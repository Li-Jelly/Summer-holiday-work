## << 和 >> 用法
+ << 叫作**流插入运算符**，数据从变量流向输出设备  
  形象记忆：cout << 数据，“把数据**送进**```cout```这个输出流”
+ >> 叫作**流提取运算符**，数据从输入设备流向变量
  形象记忆：cin >> 变量，“从```cin```这个输入流里**取出**数据放到变量里”
|操作      |        代码|        含义|
|:---------:|:----------:|:----------:|
|输出单个值|cout << 100|把整数100送到屏幕|
|输出多个值（链式）|cout << "年龄：" << 18 << "岁"|从左到右执行|
|输入单个值|cin >> age|从键盘读入一个值存入```age```|
|输入多个值|cin >> a >> b|从键盘读入两个值，分别存入a和b（空格或回车分隔）|
## ```cin``` ```cout``` ```cerr``` ```clog```
都是STL中预定义的**流对象**,定义在```<iostream>```头文件中
|对象      |全称     |作用      |默认目标|是否缓冲|
|:--------:|:-------:|:-------:|:------:|:-------:|
|cin|Character Input|标准输入，读取键盘数据|键盘|是|
|cout|Character Output|标准输出，输出普通信息|屏幕（终端）|是（先存缓存区，再输出）|
|cerr|Character Error|标准错误，输出错误信息（无缓冲）|屏幕（终端）|否（立即输出）|
|clog|Character Log|标准日志,输出日志缓存信息（有缓冲）|屏幕（终端）|是（通常重定向到日志文件）|
用法示例：
```
#include<iostream>
using namespace std;

int main(){
  int age;
  cout<<"请输入年龄：" ;   //普通提示信息 cout
  cin>>age;                //从键盘读取 cin

  if(age<0){
    cerr<<"错误：年龄不能为负数！"<<endl;    //严重错误 cerr（立即显示）
  }else{
    clog<<"用户年龄为："<<age<<endl;        //记录日志 clog（用于调试）
  }
  return 0;
}
```
## endl（End Line）
+ **换行**：在输出流中插入一个换行符'\n'，把光标移到下一行开头
+ **刷新缓冲区**（Flush）：强制把缓冲区里的所有内容立即输出到屏幕（或文件）
|特性|endl|'\n'|
|:-----:|:---:|:---:|
|换行|是|是|
|刷新缓冲区|强制刷新|不刷新（除非缓冲区满了或程序结束）|
|性能|较慢（强制刷新涉及系统调用）|较快（只往缓冲区写一个字符）|
|使用场景|调试、交互式程序（需立即看到提示）、错误信息|大量数据输出、文件写入（追求性能）|

## vector
### 是什么
```vector```是一个**可以自动扩容的数组**。它存储的元素在内存中是**连续排列**的，可以像普通数组一样通过下标[]快速访问任何一个元素
### 什么时候用
+ 需要频繁地**随机访问**元素（比如循环里用vec[i]）
+ 主要是在**尾部**添加或删除元素
+ 不确定数组到底会有多大，需要在运行时动态增加
### 怎么用
```
#include<vector>
using namespace std;

vector<int> v;      //创建一个空的整数动态数组
v.push_back(10);    //尾部插入10，v变成[10]
v.push_back(20);    //尾部插入20，v变成[10,20]
v.push_back(30);    //尾部插入30，v变成[10,20,30]

int first=v[0];     //用下标访问，first=10
int last=v.back();  //获取最后一个元素，last=30
v.pop_back();       //删除最后一个元素，v变成[10,20]

int size=v.size();  //获取当前元素个数，size=2

//遍历vector（两种常用方式）
for(int i=0;i<v.size();i++){
  cout<<v[i]<<" ";    //方式1：下标
}
for(int x:v){
  cout<<x<<" ";       //方式2：范围for(C++11)
}
```
## 范围for循环（Range-based for loop）foreach循环
### 作用
自动遍历容器中的每一个元素
```
for(int x:v){
  cout<<x<<" ";
}
```
|部分|含义|解释|
|:---:|:---:|:---:|
|int x|元素变量|定义一个变量```x```，类型是```int```。每次循环，```x```会被赋值为容器```v```中的一个元素|
|:|分隔符|读作“in”（在...中），固定写法，表示“对于在```v```中的每个元素”|
|v|容器对象|要遍历的容器，比如```vector<int>```、```数组```、```map```等|
|" "|空格|和下一个输出的数字进行分隔|
### 执行过程
```
vector<int> v={10,20,30}     //v里有3个元素

for(int x:v){
  cout<<x<<"";
}
```
编译器会把这个循环**翻译**成类似这样的代码：
```
//第一次循环：x=v[0]=10，执行cout<<10<<" ";
//第二次循环：x=v[1]=20，执行cout<<20<<" ";
//第三次循环：x=v[2]=30，执行cout<<30<<" ";
//第四次：v没有更多元素了，循环结束
```
## map(映射/字典)
### 是什么
```map```是一个键值对的容器，把**键**和**值**关联起来，可以通过键快速找到对应的值。内部是一棵**红黑树**，所以元素默认会按照大小自动排序
### 什么时候用
+ 建立一种**映射关系**，学生姓名--考试成绩
+ 根据一个唯一标识快速查找对应的数据
+ 让数据**保持有序**（按名字字母顺序遍历）
