## 函数重载
### 是什么
**函数重载**是指在同一个作用域内，可以定义多个**同名但参数列表不同**的函数。编译器会根据调用时提供的实参类型、个数、顺序，自动选择最匹配的那个函数来执行
关键点：
+ 函数名相同
+ 参数列表不同
+ **返回值类型不能作为重载的依据**
```
//合法的重载：参数列表不同
int add(int a,int b);
double add(double a,double b);
int add(int a,int b,int c);

//非法：仅返回值不同，不构成重构
int func(int a);
double func(int a);      //编译错误：重定义
```
### 为什么需要函数重载
核心价值：**用同一个逻辑名称表达同一类操作**，提升代码可读性与接口一致性
例如不用重载时，只能起不同名字：
```
int addInt(int a,int b);
double addDouble(double a, double b);
```
有了重载：
```
add(1,2);        //自动调用int版本
add(1.5,2.5);    //自动调用double版本
```
调用者不用关心底层用了哪个具体实现，接口更自然
### 重载的判定规则（重点）
1. **参数个数不同**(可行)
```
void print(int a);
void print(int a,int b);
```
2. **参数类型不同**（可行）
```
void print(int a);
void print(double a);
```
3. **参数顺序不同**（可行）
```
void show(int a,double b);
void show(double a,int b);
```
4. 仅返回值不同（不可行）
```
int get();
double get();    //错误
```
5. 仅参数名不同（不可行）
```
void f(int a);
void f(int b);      //错误：参数名不影响签名
```
6. 顶层const不能区分（对值传递）（不可行）
```
void f(int a);
void f(const int a);    //错误：与上面视为同一函数
```
7. **底层const可以区分（对指针/引用）**（可行）
```
void f(int*p);
void f(const int*p);    //OK,指向常量的指针不同

void g(int& r);
void g(const int& r);    //OK,常引用重载
```
### 重载解析（Overload Resolution）三步骤
当调用一个重载函数时，编译器按一下顺序挑选：
**第一步：确定候选函数集**
+ 同名+在调用点可见的所有函数
**第二部：筛选可行函数**
+ 实参能通过隐式转换匹配形参
+ 形参个数匹配（或可用默认参数补齐）
**第三步：选择最佳匹配**
优先级从高到低
1. 精确匹配（类型完全一致，或仅需数组->指针、函数->指针等退化）
2. const转换（如```int&```->```const int&```）
3. 提升转换（如```char```->```int``` ```float```->```double```）
4. 标准转换（如```int```->```double``` ```int```->```bool```）
5. 用户定义转换（构造函数、类型转换运算符）
如果最佳匹配有多个、无法区分，则产生**二义性(ambiguous)**编译错误
```
void f(int);
void f(double);

f(1);    //精准匹配int
f(1.5);  //精准匹配double
f('a');  //char->int（提升）优于char->double，选f(int)
f(1.0f); //float->double（提升）优于floar->int，选f(double)
```
### 二义性示例
```
void f(long);
void f(double);

f(1);    //int->long与int->double 同级，二义性，编译错误
```
```
void f(int,double);
void f(double,int);

f(1,2);      //两个都需要一次转换，无法区分->二义性
```
遇到二义性，需要显式转型：
```
f(static_cast<long>(1));    //明确指定
```
### 默认参数与重载冲突
默认参数容易和重载产生二义性：
```
void f(int a);
void f(int a,int b=0);

f(10);    //二义性：两个都能匹配
```
**建议**：不要对同一组重载函数使用默认参数，容易踩坑
### const成员函数重载（C++特有）
在类中，成员函数可以仅凭```const```修饰符重载：
```
class Demo{
public:
  int& get()      {return value;}      //非const对象调用
  const int& get() const{return value;}//const对象调用

private:
  int value=0;
};
```
调用规则：
```
Demo d;
const Demo cd;

d.get();      //选非const版本
cd.get();     //选const版本
```
### 不能重载的情况
1. 仅返回值不同——非法
2. 仅在顶层const上不同（值传递）——非法
3. 不同命名空间/类作用域——不算重载（那是名字隐藏）
4. C语言不支持函数重载——C里同名函数会冲突
>>补充：C语言通过**名字修饰**缺失，所以无法重载；C++会对函数名按参数类型编码，从而支持重载。用```extern"C"```声明的函数不能重载
### 重载VS覆盖VS隐藏
|概念|作用域|条件|
|:---:|:---:|:---:|
|重载Overload|同一作用域|同名、参数不同|
|覆盖Override|基类/派生类|虚函数、签名相同|
|隐藏Hiding|基类/派生类|同名但非虚或参数不同|
注意：派生类中定义同名函数会隐藏基类所有同名重载，除非用```using Base::func;```引入
```
class Base {
public:
    void f(int);
    void f(double);
};
class Derived : public Base {
public:
    void f(const char*);   // 隐藏了 Base::f(int) 和 Base::f(double)
};

Derived d;
d.f(10);        // 错误：Base 的版本被隐藏
d.f("hi");      // OK

// 解决：
class Derived2 : public Base {
public:
    using Base::f;          // 引入基类重载
    void f(const char*);
};
```
### 底层原理：名字修饰（Name Mangling）
编译器把函数名+参数类型编码成唯一符号，例如GCC下：
```
int add(int,int);///_Z3addii
double add(double,double);//_Z3adddd
```
这解释了为什么：
+ 返回值不参与编码->不能靠返回值重载
+ 参数类型参与编码->可以按参数重载
+ ```extern"C"不做修饰->不能重载
