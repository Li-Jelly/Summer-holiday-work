## 类型转换
### 是什么
类型转换就是把一个数据从一种类型变成另一种类型，分为**隐式转换（自动转换）** 和 **显式转换（强制转换）**
#### 隐式转换（自动）
1. 发生场景
   + 赋值时：```double d=3;``` (int转换为double)
   + 算术运算时：```3+4.5```（int转换为double）
   + 函数传参时：实参类型与形参不一致（转为形参的类型）
   + 返回值时：```return```表达式类型与函数返回类型不一致（转为函数的返回类型）
2. 转换方向
```
char/short ->int->unsigned->long->long long ->float->double->long double
```
低精度向高精度转换（安全），反过来可能**丢失精度**或**溢出**
3. 典型问题
```
int a=3.9;          //a=3 小数部分被截断
double d=1/2;       //d=0.0 1/2是整数除法
double d=1.0/2;     //d=0.5 正确
```
#### 显示转换（强制）
1. C语言风格
```
(double)x
double(x)    //函数式写法
```
+ 简单，但**不加区分**，任何类型都能转，容易出错
+ 在C++中仍可用，但不推荐
2. C++四种强制转换（推荐）
|转换方式|用途|特点|
|:---:|:---:|:---:|
|```static_cast<T>(e)|相关类型间转换，如数值、指针上行转换|编译期检查，最常用|
|```dynamic_cast<T>(e)```|多态类型间的安全向下转换|运行期检查，需虚函数|
|```const_cast<T>(e)|去除/添加```const```、```volatile```|只改限定符|
|```reinterpret_cast<T>(e)|重新解释二进制位，如指针与整数互转|最危险，平台相关|
+ static**属于类/文件本身，而不是属于某个对象**
  + static全局变量/函数：作用域被限制在当前源文件内，其他文件无法访问（相当于“文件私有”）
  + static 局部变量：变量只在第一次进入函数时初始化，之后函数调用结束也不销毁，值会保留到下一次调用，例如计数器
  + static 成员变量（C++类中）：属于整个类，所有对象共享同一份，不属于某个对象
  + static 成员函数（C++类中）：属于类，可以直接用```类名::函数名()```调用，不需要创建对象，它不能访问非静态成员
+ cast**类型转换**
  + 隐式转换（implicit cast）
  + 显式转换（explicit cast）
+ dynamic**动态的，在运行时才确定，不在编译时或写代码时就固定下来**
  + 静态（static）：编译期就确定。比如静态类型、静态绑定、静态分配
  + 动态（dynamic）：运行期才确定。比如动态类型、动态绑定、动态分配
```
double d = static_cast<double>(x);        //数值转换
Base*b=dynamic_cast<Base*>(derived);      //多态转换
const_cast<int&>(ci)=10;                  //去const
int addr=reinterpret_cast<int>(ptr);      //指针转整数
```
#### 常见转换规则与陷阱
1. 整数与浮点
  + 浮点->整数：截断小数部分（不是四舍五入）
  + 整数->浮点：可能丢失精度（如大整数转float）
2. 有符号与无符号
```
unsigned u=10;
int i=-1;
if(i<u)    //结果可能为flase，因为i被转成很大的无符号数
```
**建议**：避免有符号与无符号混用
3. 布尔转换
  + 数值->bool：0为false，非0为true
  + 指针->bool:空指针为false，非空为true
4. 字符与整数
```
char c='A';
int i=c;      //i=65(ASCII)
char c2=65;   //c2='A'
```
5.指针转换
  + 派生类指针->基类指针：隐式安全（上行转换）
  + 基类指针->派生类指针：需```dynamic_cast```或```static_cast```，否则危险
#### 构造与转换
1. 构造函数转换
```
class A{
public:
  A(int x);    //允许int 隐式转A
};
A a=10;        //隐式调用A(int)
```
用```explicit```可禁止隐式转换：
```
explicit A(int x);
A a=10;
A a(10);
```
2. 类型转换运算符
```
class A{
public:
  operator int() const {return 42;}
};
A a;
int x=a;      //调用operator int()
```
