## 赋值兼容规则
赋值兼容规则是面向对象编程中一个非常核心的概念，尤其在 C++ 这类支持继承和多态的语言里。它描述的是**派生类对象如何能够被当作基类对象来使用**。
简单说，就是：**凡是需要基类对象的地方，都可以用公有派生类的对象来替代**。
### 核心思想：is-a关系
赋值兼容规则的理论基础是 is-a（是一个） 关系。
+ 如果```Dog```公有继承自```Animal```，那么“狗**是一个**动物”。
+ 因此，任何需要“动物”的场合，用“狗”来顶替是合理的。
+ 反之则不成立：需要“狗”的地方，不能随便用“动物”替代，因为动物不一定是狗。
这就是赋值兼容规则的直观含义。
### 三种具体表现形式
在C++中，赋值兼容规则主要体现在三种场景：
1. **派生类对象赋值给基类对象**
```
class Animal { /* ... */ };
class Dog : public Animal { /* ... */ };

Dog d;
Animal a;
a = d;   // ✅ 允许：派生类对象赋值给基类对象
```
+ 这里发生的是对象切片。
+ 只把```d```中属于基类```Animal```的那部分成员复制给```a```。
+ ```Dog```特有的成员被“切掉”了，```a```里没有它们。
+ 所以```a```只是一个纯```Animal```对象，不再具有```Dog```的特性
>>注意：这里“赋值”，不是“引用”或“指针”，切片不可避免
2. **派生类对象初始化基类引用**
```
Dog d;
Animal& ra = d;   // ✅ 允许：基类引用绑定到派生类对象
```
特点：
+ 没有对象切片，ra 引用的仍然是那个完整的 Dog 对象。
+ 但通过 ra 只能访问 Animal 中声明的成员。
+ 如果 Animal 中有虚函数，且 Dog 重写了它，通过 ra 调用会触发动态绑定，执行 Dog 的版本。
```
class Animal {
public:
    virtual void speak() { cout << "Animal sound\n"; }
};
class Dog : public Animal {
public:
    void speak() override { cout << "Woof\n"; }
};

Dog d;
Animal& ra = d;
ra.speak();   // 输出 "Woof"（多态）
```
3. **派生类对象地址赋值给基类指针**
```
Dog d;
Animal* p = &d;   // ✅ 允许：基类指针指向派生类对象
```
特点：
+ 同样没有切片，指针指向的仍是完整的 Dog 对象。
+ 通过 p 只能调用 Animal 中声明的接口。
+ 虚函数机制保证多态调用。
```
Animal* p = new Dog;
p->speak();   // 输出 "Woof"
delete p;     // 若析构函数非虚，行为未定义！
```
>>重要：基类指针指向派生类对象时，基类析构函数应为 virtual，否则 delete p 不会调用派生类析构，造成资源泄漏。
### 成立的条件
赋值兼容规则不是无条件的，必须满足：
1. 必须是公有继承（public inheritance）
  + class Dog : public Animal ✅
  + class Dog : private Animal ❌ 不成立
  + class Dog : protected Animal ❌ 不成立
**因为私有/保护继承不表达 is-a 关系，而是“用……实现”的关系。**
2. 只能从派生类向基类方向赋值，不能反向
  + 基类对象/指针/引用不能自动转成派生类。
  + 反向转换需要显式类型转换（如 dynamic_cast），且不一定安全。
3. 赋值的是基类部分，访问受基类接口限制
  + 通过基类指针/引用只能访问基类中声明的成员。
  + 派生类新增成员不可见，除非向下转型。
### 为什么需要赋值兼容规则
它是多态能够工作的前提。
+ 函数参数可以声明为基类引用/指针：
```
void makeSound(Animal& a) {
    a.speak();
}

Dog d;
Cat c;
makeSound(d);   // 传 Dog，当作 Animal
makeSound(c);   // 传 Cat，当作 Animal
```
+ 容器可以存基类指针，实际指向各种派生类对象：
```
vector<Animal*> zoo;
zoo.push_back(new Dog);
zoo.push_back(new Cat);
for (auto p : zoo) p->speak();  // 多态调用
```
没有赋值兼容规则，就无法用统一接口处理不同派生类对象。
### 常见陷阱与注意事项
1. 对象切片
```
void func(Animal a) { ... }   // 按值传参

Dog d;
func(d);   // 发生切片，d 的 Dog 部分被切掉
```
**建议**：多态场景下用引用或指针传参，避免按值传递基类对象。
2. 数组不兼容
```
Dog dogs[10];
Animal* p = dogs;   // ❌ 危险！
p[1];               // 指针算术按 sizeof(Animal) 计算，不是 sizeof(Dog)
```
派生类对象数组不能当作基类对象数组使用，因为步长不同。
3. 析构函数非虚
```
Animal* p = new Dog;
delete p;   // 若 ~Animal() 非虚，只调用 ~Animal()，Dog 部分泄漏
```
规则： 只要类可能被继承并通过基类指针删除，析构函数就应为 virtual。
4. 私有继承不适用
```
class Dog : private Animal { ... };

Dog d;
Animal* p = &d;   // ❌ 编译错误
```
私有继承不满足 is-a，赋值兼容规则不成立。
