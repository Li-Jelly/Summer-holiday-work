## 默认参数
函数声明中为参数提供默认值、从而让调用方法可以省略部分实参的机制。
### 基本语法
默认参数写在**函数声明**中，用```=```给出默认值
```
void print(int a,int b=10,int c=20)

print(1);          //a=1,b=10,c=20
print(1,2);        //a=1,b=2,c=20
print(1,2,3);      //a=1,b=2,c=3
```
规则：一旦某个参数有默认值，**它右边所有参数都必须有默认值**
```
void f(int a, int b=1, int c);      //错误：c没有默认值
void f(int a=1,int b);              //错误
```
原因：实参是按位置从左到右匹配的，不能跳过中间参数
### 声明与定义的位置
默认参数只能指定一次，**通常放在声明里，定义里不要再写**
```
//头文件
void f(int a,intb=10);
//源文件
void f(int a,int b){...}      //正确，不再写=10
```
如果定义里也写，会报“重定义默认参数”：
```
void f(int a,int b=10);
void f(int a,int b=10){}      //错误
```
如果函数只有定义没有单独声明（比如在.cpp内定义），默认参数就写在定义上
同一个作用域内，可以在**不同声明**中逐步补充默认值，但不能给同一个参数默认值：
```
void f(int a,int b,int c);
void f(int a,int b,int c=3);    //可以，补充c
void f(int a,int b=2,int c);    //不可以，b在左侧，且c在前面已经赋值
```
### 调用时的匹配规则
实参按位置从左到右填充，缺省的用默认值
```
void g(int a = 1, int b = 2, int c = 3);

g();        // 1,2,3
g(10);      // 10,2,3
g(10, 20);  // 10,20,3
```
注意：默认参数不能“跳过”中间的参数。想只传```c```而不传```b```，做不到，只能显式传```b```或用其他设计（如命名参数惯用法、结构体/```std::optional```）
### 默认值的限制
默认值必须是**编译器可求值**或至少是调用点可见的表达式，常见要求：
1. 不能是**局部变量**（因为默认参数在调用点求值，作用域是声明所在作用域）：
```
void f(int x=10);      //字面量，OK

int n=5;
void g(int x=n);      //若n是全局/命名空间变量，OK；局部变量不行
```
2. 不能是**函数参数**
```
void f(int a,int b=a);    //错误：默认值不能用前面的参数
```
3. **不能依赖**```this```（对成员函数）：
```
struct S{
  int x;
  void f(int y=x);        //错误：非静态成员不能这样用
};
```
4. 可以是**函数调用、常量表达式、** ```static```**成员、全局变量、枚举**等：
```
void f(int x=getDefault());    //OK，调用点求值

struct S{static int v;};
void g(int x=S::v);            //OK
```
5. **默认值在每次调用时求值**（如果它不是常量表达式）
```
void f(int x=rand());      //每次调用f()都会重新调用rand()
```
### 与虚函数、继承的关系
**默认参数是静态绑定（编译器决定）的，而虚函数调用是动态绑定（运行期决定）的。** 二者结合时容易踩坑
```
struct Base{
  virtual void f()int x=10{cout<<"Base"<<x;}
};
struct Derived:Base{
  void f(int x=20)override{cout<<"Derived"<<x;}
};
Base*p=new Derived;
p->f();      //输出“derived 10”——函数是Derived的，但默认值取自Base
```
原因：默认值根据**指针/引用的静态类型**（```Base*```）在编译器确定，实际调用的函数体根据动态类型（```Derived```）确定
**结论：不要在虚函数中重新定义默认参数**，行为反直觉
