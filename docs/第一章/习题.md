## 1.问题
+ **样本在具体问题中指的是什么，举例回答**

样本是数据集中的一个独立观测单元，即模型的一次输入（及其对应的输出，如果有的话）

**举例（房价预测）**：一条样本=一套房子的信息（面积：120，卧室数：3，地段：市中心，房价：500万）  
**举例（图像分类）**：一张图片就是一个样本（一张猫的图片）
+ **泛化能力指的是什么**

模型“举一反三”的能力：一个模型在训练集上学到的规律，能不能在从未见过的测试集上同样表现出色  
**泛化能力强**=记住了**解题思路**，能解新题
**泛化能力弱**=记住了**标准答案**，换个数就不会了  
**泛化问题最精确的数学解释**（**偏差-方差权衡**）：  
总误差 = 偏差² + 方差 + 不可约误差
**线性回归（高偏差，低方差）**  
**深度学习（低偏差，高方差）**：把训练集换成另一组相似的点，扭曲的形状截然不同（高方差）  
**偏差** ：个体偏离群体平均水平的距离  
**方差**：数据点与平均值之间的平均距离的平方（这些结果背刺之间差别大不大）
+ **样本是不是也可以是标签**

**样本=特征（输入）+标签（输出）**

模型在**向前传播**时，只读取**输入**，并据此给出一个**预测结果**  
模型在**反向传播**时，读取**标签**，用来计算**损失函数，更新参数**
+ **关于标签需要注意：**

**推理阶段没有标签**，模型训练好投入使用时，只提供“输入”，这个时候的输入依然叫“（测试）样本”，但**不包含**标签（要预测）

**标签！=输出层的结果**  
  模型算出来的是预测值  
  标签是人为标注的
+ **为什么分类问题要用交叉熵损失，而不用平方误差，交叉熵损失具体是什么**  
  **平方误差**在分类任务的输出层（Sigmoid/Softmax）会导致**梯度消失**(梯度会乘以sigmoid导数，在两端接近0)，且它假设误差服从高斯分布，不适合离散概率输出  
  **交叉熵损失（二分类) 问题**直接衡量预测概率分布与真实分布的差异，梯度更稳定  
  **多分类**类似，用Softmax  
+ **常见的模型都有哪些（回归、分类、聚类、降维、强化学习分别举例）梳理一下这些模型的优缺点和发展**

| 任务类型 | 代表模型 | 优点 | 缺点 | 发展 |  
|:----------:|:----------:|:----------:|:------------:|:------------:|
| 回归 | 线性回归 | 简单、可解释| 拟和非线性差 |→多项式回归→GAM |  
| 分类 | 逻辑回归/SVM |效果好、理论成熟 | 大数据慢、特征工程重 | →神经网络→集成树|  
| 聚类 | K-Means | 快速、易理解 | 需预设K、对初始值敏感 | →DBSCAN→谱聚类|  
| 降维 | PCA | 线性降维快速 | 无法处理非线性 | →t-SNE→UMAP|  
| 强化学习 | DQN | 解决序列决策 | 样本效率低、训练不稳 | →PPO→离线RL|  

+ **梯度下降算法和学习率分别应用在哪类问题中，怎么区分什么时候用梯度下降，什么时候用学习率**  
**梯度下降**是**优化算法**，用于所有可微分损失函数的训练模型（回归、分类、深度学习等）  
**学习率**是**超参数**，控制梯度下降每一步的步长
  
**区分**：梯度下降是“方向”（怎么更新），学习率是“步子大小”（更新多少），二者配合使用
+ **分类问题和聚类问题有什么不同**

|    | 分类| 聚类|
|:------:|:------:|:--------:|
|是否有标签|有（监督学习）|无（无监督学习）|
|目标|预测新样本类别|发现数据内在分组|
|输出|离散类别|簇编号（无实际语义的索引号）|
+ **只从标签上就能区分出哪类问题是回归问题吗，这些问题种类还有没有其他的特征**  
  **不只看标签**：回归模型是连续实数（房价），分类标签是离散类别（猫/狗）
  **其他特征**：
  输出空间是否有序（回归通常有序，数值大小有意义）
  损失函数选择（平方误差vs交叉熵损失）
  评估指标（RMSE vs Accurancy）
## 2.假设你想建立一个机器学习系统，来预测某一天某个城市共享单车的租借数量（辆）。请详细指出：
**数据：你需要收集哪些历史数据？每个样本的特征可能有哪些（至少列5个）？**

历史数据：某过去一年的共享单车租借量（标签/样本划分为两个数据集）  
特征：时间，街区，天气，投放数量,**节假日/工作日，温度/降水量，风速等平均骑行时长、上一时段租借量**

**标签是什么？**  
某城市某日共享单车真实租借数量（连续值）

**模型：从这个问题的性质看，它属于回归还是分类问题？你会选择什么类型的简单模型来开始？**  
属于回归问题，可以用线性回归模型开始

**目标函数：你会选择哪个损失函数来评估模型的好坏？为什么？**  
用平方误差来评估，因为这个问题本身是一个回归问题

**优化算法：你会采用什么算法来最小化这个损失函数？**  
梯度下降或者学习率都可以

**为什么线性回归模型可以解决这类问题**  
+ **预测目标本身就是“线性叠加”的：**
  共享单车每日租借总量Y本质上是多个独立因素的加和效应：
  Y = β₀ + β₁ · 温度 + β₂ · 是否周末 + β₃ · 小时雨量 + ⋯ + ϵ
  这些因素的影响在宏观统计上近似可加，线性回归就是去找每个因素对应的“权重系数”虽然真实世界有交互效应（比如下雨天温度低的影响被放大），但在每日总量的宏观层面，线性叠加已经能解释70%~80%的方差，足够用于调度决策  
+ **为什不用神经网络或随机森林**
  **数据量有限**：一个城市的单车数据，按天计可能只有1~2年的样本（几百到一千条），深度学习在这种情况下容易过拟合，而线性回归泛化能力更强
  （深度学习的参数百万甚至上亿个，数据量很少的情况下模型会“强行扭曲”参数，记住样本的每一个细节，包括**噪声**和**背景**）
  （一亿个未知数，100个方程）  
  **线性回归泛化能力更强**：假设只有1个特征，参数就是斜率和截距（2个），若有10个样本，方程数远大于未知数，模型没法精确穿过每一个点，只能被迫找一条让整体误差最小的直线，这条线太简单了，没法弯曲，所以**忽略掉了数据中的随机噪声**，只捕捉到了数据最粗粒度的上升或下降趋势，新数据来了虽然在训练集上得分不高（可能有误差），但在测试集上反而表现稳定，**因为参数太少，数据相对足够，模型“没资格”过拟合，只能抓主要矛盾**（开个小差：深度学习的理论能不能反过来作为神经科学的依据呢？这个地方咋一看很有生物学上的规律）  
  **直观对比**：
  **线性回归**（**高偏差，低方差**）：一支直尺，给10个点，只能画一条直线，不能穿过每个点，但抓住了“总体上升”的趋势  
  **深度学习**（**低偏差，高方差**）：一根极其柔软的绳子，给10个点，可以把绳子扭曲成任意形状，完美穿过每一个点，但这个扭曲的形状完全取决于这10个点的随机位置，换一组点，绳子形状就面目全非  
  **核心结论**：泛化能力强弱，本质是模型复杂度与数据量的博弈
  + **参数数量**>>**数据样本数**：模型自由度极高，可以记住所有噪声，泛化边界极窄
  + **参数数量**>>**数据样本数**：模型自由度极低，被迫平均化，泛化边界较宽
  + 非要在大数据场景下用深度学习，数据少，常用解决方法是**正则化**（L2正则化、Dropout）和**数据增强**，**人为降低模型的有效容量**，让深度学习变“笨一点”，从而向线性回归的“泛化优势”靠拢

## 4.(过拟合思想实验) 小明用所有已知的达芬奇和毕加索画作训练AI，训练集准确率100%，但识别一幅从未见过的新达芬奇真迹时，却错判为毕加索。请结合过拟合分析原因和改进建议。
### 可能出错的原因
+ **训练集太小或太偏**（所有达芬奇画作风格单一，而新画作风格不同）  
+ **模型复杂度过高**（参数过多，记住了训练集的噪点、纹理细节，而非通用特征）
+ **数据预处理不一致**（训练集画作都是高清，新画作有刮痕或不同光照）
+ **验证确实**（没有划分验证集来早停）
+ **注释**：**数据预处理**不一致是**语义过拟合**或**领域过拟合**，模型会把“清晰度”当作区分画作的核心依据  
  **刮痕**：训练集未出现，模型会当作“异常信号”，输出极低的置信度，甚至胡乱分类  
  **不同光照**：光照会改变画作局部的**对比度和边缘锐度**。如果训练时模型过度依赖“边缘锐利程度”来判断是“现代油画”还是“古典素描”，那新画作在柔光下拍摄，边缘变模糊，模型就会误判为“古典”类，尽管画风完全不是。
  **数据预处理**打破了**独立同分布假设**：机器学习模型都默认一个前提：**训练集和测试集的数据来自同一个分布**，当训练集全是“高清+正面光”，测试集出现“刮痕+侧光”，数据分布变了，此时模型在训练集上表现极好（低偏差），但在新数据上极差（高方差）——**学得太偏了**（统计学上称这种过拟合为**斜变量飘逸**）
  **应对方法**：
  **数据增强（最有效）**：训练阶段主动对高清训练图施加“随机刮痕模拟”“随机光照调整”“高斯模糊”和“对比度抖动”，让模型明白“画面质量”是无关变量，改变它不影响画作类别
  **频域过滤**：在输入模型前，将图像转为频谱图，过滤掉高频细节（刮痕属于高频噪点），强制模型只学习**中低频的宏观构图和色彩分布**。
## 5.(损失函数与优化) 假设你有一个非常简单的模型 y=w⋅x，其中 x 是输入特征，w 是模型唯一的参数，y 是预测值。你的训练数据集包含两个点：(x=1,y=1) 和 (x=2,y=4)。
+ **备注**：

|名称|公式|
|:-----:|:------:|
|平方误差损失函数|$L = (y - \hat{y})^2$|
|均方误差|MSE = (1/n) · Σ(yᵢ - ŷᵢ)² |
|平均绝对误差|MAE = (1/n) · Σ\|yᵢ - ŷᵢ\| |
|矩阵实现|$loss = \frac{1}{n} \sum_{i=1}^{n} (input_i - target_i)^2$|

|字母|含义|
|:----:|:-----:|
|L|损失值（样本误差）|
|y|真实值（标签）|
|\hat{y}|预测值|
|(y-\hat{y})|残差（预测偏离真实的程度）|
|平方|让误差恒为正，并放大较大的误差|
|MSE|Mean Squared Error（整个数据集平均的平方误差）|
|input|模型的预测输出（对应\hat{y}）|
|target|真实的目标标签（对应y）|
|1/2|求导方便|
+ **请写出这个问题的平方误差损失函数（即两个数据点的平均损失）关于参数 w 的表达式。**  
  $$L(w) = \frac{1}{2} \Big[ (1 \cdot w - 1)^2 + (2 \cdot w - 4)^2 \Big]$$
  两个点的平方差相加
+ **你能直接计算出使损失函数最小的最优参数w是多少吗？**
  对 L(w) **展开求导**并令w为0：
  $$L(w) = \frac{5}{2}w^2 - 9w + \frac{17}{2}$$
  $$L'(w) = 5w - 9$$
  w=1.8
+ **如果使用梯度下降算法来优化，学习率为 0.1，从 w=0 开始进行第一次迭代，请计算出更新后的 w 值。（提示：你需要先求出损失函数关于 w 的梯度）。**  
  $$L'(0) = (0 - 1) + 2(0 - 4) = -1 - 8 = -9$$
