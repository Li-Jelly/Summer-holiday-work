# 机器学习四大核心
## 数据
+ 样本：一个独立的数据点  
+ 特征：描述样本属性的变量，通常是向量形式（预测房价参考的面积、地段、房龄）  
+ 标签：**要预测的目标值**（监督学习中标签是已知的）  
+ 数据集：**训练集**（学习参数）和**测试集**（评估模型泛化能力）
## 模型
将特征映射到标签的数学函数（**Faction describe the world!!!**）  
模型通常是由多层神经元构成的复杂神经网络（现在的深度学习已经不追求神经学上的解释，但有部分模型会严格对应神经学上的一些现象），每层都对输入数据进行某种变换
## 目标函数（优化的指挥棒）
通常是一个**损失函数**，用来量化模型**预测值**与**真实值**之间的差距
+ **平方误差**：常用于回归问题L=1/2​(y^​−y)2  
+ **交叉熵损失**：常用于分类问题，衡量两个概率分布之间的差异
+ 训练的目标就是**最小化**损失函数
## 优化算法（更新模型降低损失函数的值）
+ **梯度下降（核心算法）**：计算损失函数关于模型参数的梯度，指明了损失函数上升最快的方向，为了最小化损失，让参数沿梯度的反方向进行微小的调整  
+ **学习率**：一个超参数，控制每次参数更新的步长。太大震荡，太小收敛太慢。
#机器学习的问题谱系
##监督学习：数据有标签，应用最广
+ **回归**：标签是连续值（房价预测、股票预测、气温预测）  
+ **分类**：标签是离散值（手写数字识别、猫狗分类、垃圾邮件识别）  
**二者本质区别**：输出的空间是连续的还是离散的（而非模型本身）  
**逻辑回归**：本质是分类模型
