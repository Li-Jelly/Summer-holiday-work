## MES
### MES（均方损失函数）
#### 为什么能训练回归
回归任务的输出是连续值（如房价、温度），MSE 的设计与回归的目标天然契合。
1.  从概率角度看：等价于高斯噪声下的最大似然估计
假设真实值 yy 由模型输出 f(x)f(x) 加上高斯噪声 ϵϵ 生成：  
$y = f(x) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$  
那么给定x,y的条件概率为：  
$p(y|x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(y - f(x))^2}{2\sigma^2}\right)$
对所有样本取对数似然：
$\log L = -\frac{n}{2} \log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^n (y_i - f(x_i))^2$
**最大化对数似然**等价于**最小化**$\sum (y_i - f(x_i))^2$,也就是最小化MSE
>>结论：MSE隐含了“误差服从高斯分布”的假设，这正是回归任务中最常见的噪声模型
2.  从优化角度看：梯度性质好
MSE 对预测值 y^y^​ 的梯度是：  
$\frac{\partial MSE}{\partial \hat{y}} = \frac{2}{n} (\hat{y} - y)$
+ 梯度与误差成正比，误差越大，更新力度越大；
+ 处处可导、光滑，适合梯度下降；
+ 损失函数是凸的（对线性模型而言），能保证收敛到全局最优。
3.  从几何角度看：衡量欧氏距离
MSE 本质上是在衡量预测向量与真实向量之间的欧氏距离的平方。回归任务的目标就是让预测点尽可能接近真实点，MSE 直接量化了这个"接近程度"。
#### 为什么MSE也能用于分类
分类任务的输出通常是离散类别，直觉上 MSE 不太合适。但在实践中，它确实可以用于分类，原因如下：
1.  通过 One-Hot 编码把分类变成"回归"
对于 KK 类分类，把真实标签编码为 One-Hot 向量：  
y=[0,0,1,0](第3类)
模型输出经过 Softmax 后得到概率向量 y^=[0.1,0.2,0.6,0.1]y^​=[0.1,0.2,0.6,0.1]。
此时可以把每个类别的概率看作一个连续值，用 MSE 衡量预测概率与 One-Hot 目标的差异：
$MSE = \frac{1}{K} \sum_{k=1}^K (y_k - \hat{y}_k)^2$
这样就把它转化成了一个"对每个类别做回归"的问题。
3.  梯度仍然有效
以 Softmax + MSE 为例，梯度仍然可以正常反向传播，模型参数能够被更新。虽然梯度形式比交叉熵复杂，但数学上是可行的。
4.  理论上也能对应一种概率解释
MSE 对应的是高斯分布假设。如果强行把类别标签看作高斯变量，MSE 就是对应的最大似然估计。只是这个假设对分类问题并不自然，所以效果通常不如交叉熵。
### 与交叉熵损失对比
假设真实类别是第 3 类（One-Hot 为 [0,0,1][0,0,1]），模型预测：
+ 情况 A：[0.1,0.1,0.8][0.1,0.1,0.8] —— 预测较正确
+ 情况 B：[0.4,0.4,0.2][0.4,0.4,0.2] —— 预测错误
MSE 对这两种情况的惩罚差距，远小于交叉熵的差距。交叉熵会严厉惩罚"把正确答案预测成低概率"的行为，而 MSE 的惩罚相对温和。
