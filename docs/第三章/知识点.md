## 线性回归
线性回归是**最基础的监督学习模型**，用于预测**连续值**（如房价、气温、销售额），线性回归可以看作**单层神经网络**
### 数学模型
假设输入有d个特征，输出为标量y，线性回归假设：

$\hat{y} = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b$  
用向量形式写成：

$\hat{y} = \mathbf{w}^\top \mathbf{x} + b$  
其中 $\mathbf{w} \in \mathbb{R}^d$ 是**权重向量**， $b \in \mathbb{R}$ 是偏置
### 损失函数——均方误差
衡量预测值 $\hat{y}$ 与真实值y的差距：

$L(\mathbf{w}, b) = \frac{1}{2n} \sum_{i=1}^n \left( \hat{y}^{(i)} - y^{(i)} \right)^2$  
前面的1/2是为了求导时抵消平方项产生的系数2，方便计算  
损失函数是**所有样本的平均损失**，计算成本太高，一般用**小批量随机梯度下降**
### 解析解
对于线性回归，损失函数是**凸函数**，存在**解析解**

$\mathbf{w}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$  
但实际中数据量太大时求逆矩阵代价过高，会用**梯度下降**迭代求解
## 神经网络源于神经科学
真正的神经元，**超过阈值向下一个神经发射信号**
## 梯度下降
核心思想：沿着**损失函数下降最快的方向**（即负梯度方向）更新参数
### 方向导数
#### 定义
360°方向都对应一个方向导数，可以理解为朝某个特定方向迈出一小步，**函数值变化的快慢（变化率）**
+ 你朝正北试探着迈一小步——发现海拔升高了 5 米（方向导数为 +5）
+ 你朝正东试探着迈一小步——发现海拔升高了 3 米（方向导数为 +3）
+ 你朝西南试探着迈一小步——发现海拔下降了 10 米（方向导数为 -10）
#### 梯度和方向导数的关系
梯度向量的方向就是**方向导数取得最大值的方向**
### 梯度
#### 定义
梯度是一个**向量**，它的每个分量是函数对对应变量的导数
假设 $\mathbf{w} = (w_1, w_2, \dots, w_n),$ 
$\nabla f(\mathbf{w}) = \left( \frac{\partial f}{\partial w_1}, \frac{\partial f}{\partial w_2}, \dots, \frac{\partial f}{\partial w_n} \right)$

1. **方向**：梯度向量的方向，就是由各个偏导数的正负号和大小比例共同决定的
2. **大小**：梯度向量的长度（模长），代表了函数在该点出**最陡峭的变化率**  
正因为梯度是由所有偏导数组成的，它才天然地包含了“在哪个变量上调整多少才能最有效影响函数值”的全部信息  
**注意**：梯度只在当前点的**极小邻域内**才准确代表下降方向，一旦迈大步，地形就变了（函数的曲率变了），原来的方向可能已经不再是下降方向了。
### **参数更新规则**

$\mathbf{w} \leftarrow \mathbf{w} - \eta \frac{\partial L}{\partial \mathbf{w}}$  

$b \leftarrow b - \eta \frac{\partial L}{\partial b}$  
其中 $\eta$ 是**学习率**，控制每次**步长**
#### 步长大小
##### 步长太小
+ **现象**：每次只移动一厘米
+ **后果**：虽然方向是对的（一直在下降），但到达山底需要很多步。意味着**训练时间极长**，**计算资源浪费**，很容易**陷入局部最优**（步子太小跨不出）
##### 步长太大
+ **现象**：每次迈的步伐极大，像在跳远
+ **后果**：可能会直接**跨过**山底，跳到对面山坡上，**损失函数值忽大忽小（震荡）**，甚至**越跳越高（损失发散，变为无穷大）**，永远无法收敛
#### 解决方法
+ **学习率衰减**：随着训练进行慢慢减小步长
+ **自适应优化器**
### 三种变体
|方法|描述|特点|
|:---:|:---:|:---:|
|批量梯度下降(BGD)|用全部数据计算梯度|准确但慢|
|随机梯度下降(SGD)|每次随机选1个样本计算梯度|快但噪声大，不稳定|
|**小批量随机梯度下降(Mini-batch SGD)**|每次选b个样本|最常用，兼顾速度与稳定性|
#### 批量大小选择
+ **不能太小**：每次计算量太小，不适合**并行**来最大利用计算资源
+ **不能太大**：内存消耗增加，浪费计算（例如，如果所有样本都是相同的）
>>PyTorch 实现：```torch.optim.SGD(model.parameters(),lr=0.01)```默认就是mini-batch SGD
### 梯度下降一定能收敛到全局最优吗
1. **凸函数**（大碗形状）：能收敛到全局最优
+ 碗底只有一个最低点，只要**步长合适**，无论从哪里出发，最终都能稳稳滑倒碗底（全局最优）
2. **非凸函数**（连绵起伏的山脉）：大概率卡在局部最优或鞍点
现实中的深度神经网络损失函数是极其复杂的**非凸函数**，地形像喜马拉雅山脉一样起伏不平
+ **局部最优**：小盆地，周围都比它高，但不知道远处还有更深的峡谷。此处梯度为0，下降算法会认为“到底了”，于是停在这里
+ **鞍点**：更常见的情况。在一个方向上它看起来是下坡（梯度为负），但在另一个方向上看起来是上坡（梯度为正）。梯度在这点的值非常接近0，导致下降极其缓慢，像在平地上原地踏步，误以为收敛了
3. **反常现象**：在极高维度的深度学习中，局部最优反而没那么可怕
+ 高维空间里，要成为一个真正的局部最优（所有方向都是上坡）是极其困难的
+ 真正的难点反而是“鞍点”
+ 在实际应用中，找到一个“足够好”的局部最优解，通常已经能让模型表现得很出色了，并不一定要找到数学上的绝对全局最低点

```

```
+ **作用**：随机打乱索引列表
+ **具体**：```random.shuffle(indices)```会将```indices```列表原地打乱，变成```[342,19,887,56,...]```
+ **为什么如此重要**：
  + 如果数据有某种顺序（比如前500个是类别A，后500个是类别B），按顺序训练会导致模型偏向最新看到的数据
  + 随机打乱可以保证每个批次的数据分布接近整体分布，让训练更稳定、泛化能力更好
  + 此时样本已经以张量形式传入了函数，但打乱的是**索引**，**不是数据本身**（数据不动，只改变访问顺序，不用复制数据节省内存，只操作索引高效）
```
for i in range(0,num_examples,batch_size):
```
+ **作用**：按批次大小遍历所有样本
+ **具体**：```range(0,num_examples,batch_size)```生成从0开始、步长为```batch_size```的序列。例如```batch_size=10```时，生成```0,10,20,30,...```
+ **批量大小**：```batch_size```（批量大小）
  + 不是字节数，是**样本数量**
  + 表示每个小批量中包含多少个样本
  + 常见取值：32，64，128，256
+ **批次**：
  + 把全部数据分成若干组，每组叫一个”批次“
  + 例如1000个样本，batch_size=64
    + 批次1：样本0-63（64个）
    + ...
  + 每次循环处理一个批次的索引(**学习率设置得当，和全部计算一样最后会收敛到同一个最优解**，且因为有噪声，反而**更容易跳出局部最优**)
+ **迭代**：
```
# 循环（Loop）：代码结构
for i in range(10):    # 这是循环语句
    print(i)

# 迭代（Iteration）：取元素的过程
iterable = [1, 2, 3, 4]
for 元素 in iterable:  # 这是迭代过程
    print(元素)        # 每次迭代取一个元素
```
+ 循环是**怎么写代码**
+ 迭代是**怎么取数据**
+ **小批量处理**：每次只返回```batch_size```个样本，而不是一次性返回全部，兼顾效率和稳定性
  + 数学上，小批量样本的梯度均值是所有样本梯度均值的**无偏估计**，且方差缩小了64倍
  + 通过**平均多个样本的梯度**，抵消了单个样本的随机噪声
  + 噪声方差与batch_size成**反比**（batch_size越大越稳定）
  + 但不是越大越好：稳定性收益递减，计算成本线性增加
  + 一般用batch_size=64/128

+ **具体**：
  + ```indices[i:min(i+batch_size,num_examles)]```切片取出从```i```到```i+batch_size```（但不超过总样本数）的索引
  + 最后一个批次可能不足```batch_size```，所以用```min```防止越界，如min（1024,1000），如果最后一个批次最后一个数小于1000，按最后一个算，大于则按照1000算
  + ```torch.tensor(...)```将Python列表转换为PyTorch张量（**list只支持整数或切片，不能进行索引**）```features```是PyTorch张量
    + PyTorch支持**高级索引**：用一个张量作为索引，批量提取数据
    + 这样比循环逐个提取快的多（底层用C++实现）
+ **例子**：如果打乱后```indices```的前10个是```[342,19,887,56,731,204,98,415,672,109]```，那么第一个```batch_indices```就是这10个数字组成的张量
```
yield features[batch_indices],labels[batch_indices]
```
+ **作用**：这是一个**生成器**，使用```yield```关键字
+ **具体**：
  + ```features[batch_indices]```根据索引从特征矩阵中取出对应的行（样本）
  + ```labels[batch_indices]```根据索引从标签向量中取出对应的标签
  + ```yield```会返回当前批次的数据，但函数不会结束，而是暂停，等下次被调用时从暂停出继续执行
    + 循环到yield的batch_indices就暂停循环，返回批次1暂停
    + 只要函数体内有```yield```关键字，Python就将其识别为生成器函数
      + **普通函数**：```return```一次性返回所有结果，函数结束（同时存储N个批次）
      + **生成器函数**：```yield```逐步产生结果，保留函数状态，下次调用从```yield```处继续（同时存储1个批次）
+ **优势**：不需要一次性把所有批次数据都加载到内存，而是按需生成，节省内存
  + 停下之后，CPU/GPU**去执行训练代码**（反向传播等）了
+ **输出**：
  + batch_indices**包含了64个索引**
  + features[batch_indices]**取出了64个样本**
  + **循环一次 = 执行一轮for循环 = 产生一个批次 = 暂停一次**

+ 模型的**权重参数**：```w=```
+ ```torch.normal(0, 0.01, size=(2, 1), requires_grad=True)```
  + ```torch.normal(mean, std, size)```：从**正态分布**中随机采样生成张量
  + ```0```：均值，表示以0为中心
  + ```0.01```：标准差，表示数值在0附近小范围波动
  + ```size=(2,1)```：生成一个2行1列的矩阵，因为数据有两个特征，需要两个权重值
  + ```requres_grad=True```：**关键参数**，表示PyTorch需要追踪这个张量的所有运算，以便后续自动计算梯度
    + PyTorch的自动微分
      + 当```requires_grad=True```时，PyTorch会记录所有对这个张量的操作
      + 构建一个**计算图**，记录数据流向
      + 调用```.backward()```时，自动计算每个```requires_grad=True```的张量的**梯度**
      + 梯度存储在张量的```.grad```属性中
  + 实际效果：
```
    # w 会是一个类似这样的张量（数值随机）：
tensor([[ 0.0087],
        [-0.0053]], requires_grad=True)
```
  + **正态随机初始化**：
    + **正态分布**：随机初始化可以打破对称性，防止所有神经元学习到相同的特征
    + **随机值而非固定值**：如果所有权重初始化为0，多有神经元在反向传播时更新幅度相同，无法学习不同的特征
    + 如果```w=[0,0]```，那么所有样本的计算结果```Xw=0```，梯度更新时每个权重的更新量完全相同，最终两个特征学到的权重会一摸一样，**无法区分特征的重要性**
+ 模型的**偏置参数**```b=```
+ ```torch.zeros(1,requires_grad=True)```
  + ```torch.zeros(1)```：生成一个**全0**的张量，形状为（1，）即一个标量
  + ```requires_grad=True```：同样需要追踪
  + 实际效果：
```

```
#### 定义模型
```
def linreg(X,w,b):
  """线性回归模型。"""
  return torch.matmul(X,w)+b
```
+ ```linear regression```线性回归缩写
+ 结果形状：（batch_size,1）
+ 通过**广播机制**，```b```会自动扩展到与矩阵乘法结果相同的形状```(batch_size,1)```
+ 即每个样本的的预测值都加上同一个偏置
#### 定义损失函数
```
def squared_loss(y_hat,y):
  """均方损失。"""
  return(y_hat-y.reshape(y_hat.shape))**2/2
```
+ ```def``` 定义一个新函数
+ ```squared_loss```：函数名，表示“平方损失”
+ **形状对齐** ```y.reshape(y_hat.shape)```
  + ```y_hat```形状：```(batch_size,1)```，比如```(10,1)```
  + ```y```的形状：```(batch_size,)```，比如```(10,)```
  + 直接相减会得到```(10,10)```的错误结果（广播机制导致）
  + 需要把```y```也变成```(10,1)```，保证逐元素相减
#### 定义优化算法
```
def sgd(params,lr,batch_size):
  """小批量随机梯度下降。"""
  with torch.no_grad():
    for param in params:
      param-=lr*param.grad/batch_size
      param.grad.zero_()
```
+ ```sgd```函数名：Stochastic Gradient Descent(随机梯度下降)的缩写
+ 参数：
  + ```params```：模型的**所有参数列表**，通常是```[w,b]```
  + ```lr```：学习率，控制每次更新的步长
  + ```batch_size```：批量大小，用于平均梯度
+ ```torch.no_grad()```：一个**上下文管理器**，临时禁用梯度追踪
  + 在参数更新时，不需要记录这些操作的梯度
  + 避免构建不必要的计算图，节省内存和计算
  + 防止不小心在更新参数时产生新的梯度
  + 如果没有：
```
#如果不用torch.no_grad()
param=param-lr*param.grad/batch_size  #这会在计算图中记录
#下次backward()时，会追踪到更新操作，造成计算图混乱

#使用torch.no_grad()
with torch.no_grad():
  param-=lr*param.grad/batch_size  #不追踪，只是数值更新
```
+ **遍历所有参数**
  + 遍历传入的参数列表，对**每个参数**执行更新
  + 例如```params=[w,b]```，则先更新```w```，再更新```b```
+ **参数更新公式**
  + 数学表达
```
θ ← θ - (lr / batch_size) * ∇θ
```
  + **第一步：计算平均梯度**```param.grad/batch_size```
    + ```param.grad```：当前参数的梯度（形状与参数相同）
    + 除以```batch_size```是为了**平均化**，因为```loss.sum().backward()```计算的是总损失对每个样本的梯度之和，我们需要的是平均梯度（学习率不会受batch_size大小的影响）
  + **第二步：乘以学习率**```lr*平均梯度```
    + ```lr```：学习率，控制步长
    + 如果学习率太大，可能跳过最优点；太小，收敛太慢
  + **第三步：更新参数**```param-=...```
    + 沿**负梯度方向**移动（梯度是上升方向，减梯度是下降方向）
    + 原地更新参数值
+ **清零梯度**
  + ```zero_()```将参数的梯度张量原地清零
    + PyTorch默认**累积梯度**
    + 如果不清零，下一次```.backward()```会把新梯度加到旧梯度上
    + 这会导致梯度越来越大，训练失败

```

+ ```num_epochs=3```训练轮数设为3，表示完整遍历整个数据集3次

+ ```loss=squared_loss```将损失函数赋值给别名```loss```，使代码更简洁
```

  for X, y in data_iter(batch_size,features,labels):
    l=loss(net(X, w, b),y)
    l.sum().backward()
    sgd([w, b], lr, batch_size)

+ **外层循环**：控制训练轮数，每轮完整遍历一次数据集
+ **内层循环**：遍历每个批次的数据，```X```是当前批次的特征，```y```是当前批次的标签
+ ```l=loss(net(X,w,b),y)```前向传播+计算损失。先通过模型计算预测值，再用损失函数计算每个样本的损失，得到的形状为```(batch_size,1)```的张量
+ ```l.sum().backward()```将所有样本的损失求和得到一个标量，然后反向传播计算梯度，求和是因为```backward()```只能对标量求导
+ ```sgd([w,b],lr,batch_size)```用计算出的梯度更新参数```w```和```b```，同时清零梯度，防止累积
+ ```with torch.no_grad()```禁用梯度追踪，这里只是评估模型，不需要计算梯度，节省内存
+ ```train_1=loss(net(features,w,b),labels)```用**整个数据集**计算当前模型的损失（不是批次），评估整体表现
+ ```print(f'epoch{epoch+1},loss{float(train_l.mean()):f}')```打印当前epoch的平均损失```train_1```是形状```（1000，1）```的张量，```.mean()```求平均，```float()```转为Python浮点数，```:f```表示以浮点数格式输出

## Softmax回归
虽然叫“回归”，但它是**分类模型**，用于预测**离散类别**（如手写数字0~9）
+ **回归**：估计一个**连续值**
  + 但连续值输出
  + 自然区间R
  + 跟真实值的区别作为损失
+ **分类**：预测一个**离散类别**
  + 通常多个输出
  + 输出i是预测为第i类的置信度

### 从线性回归到多分类
我们希望模型输出**属于每个类别的概率**，且这些概率必须满足：
+ 非负
+ 总和为1

+ 首先进行编码
  + n个类别用一位有效编码（只有一个y=1,其余的都为0）
+ 使用均方损失训练
+ 最大值最为预测（正确类别的置信度特别大）  
$\hat{y} = \arg\max_i o_i$  
+ 需要更置信的识别正确类（大余量）  
$o_y - o_i \geq \Delta(y, i)$
+ 输出匹配概率（非负，和为1）  
$\hat{y} = \text{softmax}(\mathbf{o})$  

$\hat{y}_i = \frac{\exp(o_i)}{\sum_k \exp(o_k)}$
+ 概率y和 \hat{y} 的区别作为损失
+ 交叉熵常用来衡量两个概率的区别  
$H(p, q) = \sum_i -p_i \log(q_i)$
+ 将它作为损失
$l(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_i y_i \log \hat{y}_i = -\log \hat{y}_y$
+ 其梯度是真实概率和预测概率的区别(只关心正确类的预测值)
$\partial_{o_i} l(\mathbf{y}, \hat{\mathbf{y}}) = \text{softmax}(\mathbf{o})_i - y_i$
Softmax函数就是做这件事：

$\hat{y}_k = \text{softmax}(\mathbf{o})_k = \frac{\exp(o_k)}{\sum_{j=1}^K \exp(o_j)}$  

其中K是类别总数， \(\mathbf{o} = \mathbf{Wx} + \mathbf{b}\)  是未归一化的 **logits**
### 交叉熵损失
用于衡量**两个概率分布**之间的差异，假设真实标签的one-hot向量为y，则：

$L = -\sum_{k=1}^K y_k \log \hat{y}_k = -\log \hat{y}_{\text{true}}$  

直观理解：只鼓励模型对正确类别的预测概率尽可能大
### 损失函数（衡量真实值与预测值之间的区别）
#### L2 Loss（均方损失）
当预测值离真实值比较远的时候，L2 Loss会用很大的梯度进行更新
##### 公式
$l(y, y') = \frac{1}{2}(y - y')^2$
##### 图像
+ 损失函数（蓝色）
+ 似然函数（绿色）
+ 梯度（橙色）

#### L1 Loss（绝对值损失）
当预测值离真实值比较远的时候，L1 Loss梯度会用同样的力度进行更新
##### 公式
$l(y, y') = |y - y'|$

+ 似然函数（绿色）

#### Huber's Robust Loss(鲁棒损失)
##### 公式
$l(y, y') =
\begin{cases} 
|y - y'| - \frac{1}{2} & \text{if } |y - y'| > 1 \\ 
\frac{1}{2}(y - y')^2 & \text{otherwise}
\end{cases}$

+ 绝对值函数后面-1/2是为了让图像链接起来
+ 梯度下降优化
  + 真实值和预测值差距比较大：均匀地向原点回拉
  + 真实值和预测值差距比较小：不会产生突变，优化比较平滑

|噪声分布类型|概率密度形状|对应损失函数|典型应用场景|
|:----:|:---:|:---:|:---:|
|高斯分布|钟形曲线（轻尾）|MSE(L2)|图像超分、物理模拟、传统回归|
|拉普拉斯分布|尖峰+重尾|MAE(L1)|金融风险、异常检测、有离群点的回归|
|Huber分布（混合）|中间高斯+两边拉普拉斯|Huber Loss|工业界通用鲁棒回归（自动驾驶测距）|
|Logistic分布|类似高斯但尾巴稍重|交叉熵损失（分类）|二分类/多分类（输出概率）|
|泊松分布（离散）|右偏分布（长尾巴）|泊松负对数似然|计数预测（如一天内到店顾客数）|
|Beta分布|[0,1]区间上的任意形状|Beta负对数似然|点击率预测（CTR）中的转化率|
|学生t分布|极重尾（比拉普拉斯更重）|t-分布损失|存在大量离谱离群点的鲁棒回归|
|高斯混合分布|双峰/多峰|GMM损失|多模态数据（如不同光照下的同一物体）|

def accuracy(y_hat, y):  #@save
    """计算预测正确的数量"""
    if len(y_hat.shape) > 1 and y_hat.shape[1] > 1:
        y_hat = y_hat.argmax(axis=1)
    cmp = y_hat.type(y.dtype) == y
    return float(cmp.type(y.dtype).sum())

accuracy(y_hat, y) / len(y)

def evaluate_accuracy(net, data_iter):  #@save
    """计算在指定数据集上模型的精度"""
    if isinstance(net, torch.nn.Module):
        net.eval()  # 将模型设置为评估模式
    metric = Accumulator(2)  # 正确预测数、预测总数
    with torch.no_grad():
        for X, y in data_iter:
            metric.add(accuracy(net(X), y), y.numel())
    return metric[0] / metric[1]

class Accumulator:  #@save
    """在n个变量上累加"""
    def __init__(self, n):
        self.data = [0.0] * n

    def add(self, *args):
        self.data = [a + float(b) for a, b in zip(self.data, args)]

    def reset(self):
        self.data = [0.0] * len(self.data)

    def __getitem__(self, idx):
        return self.data[idx]
```

def train_epoch_ch3(net, train_iter, loss, updater):  #@save
    """训练模型一个迭代周期（定义见第3章）"""
    # 将模型设置为训练模式
    if isinstance(net, torch.nn.Module):
        net.train()
    # 训练损失总和、训练准确度总和、样本数
    metric = Accumulator(3)
    for X, y in train_iter:
        # 计算梯度并更新参数
        y_hat = net(X)
        l = loss(y_hat, y)
        if isinstance(updater, torch.optim.Optimizer):
            # 使用PyTorch内置的优化器和损失函数
            updater.zero_grad()
            l.mean().backward()
            updater.step()
        else:
            # 使用定制的优化器和损失函数
            l.sum().backward()
            updater(X.shape[0])
        metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
    # 返回训练损失和训练精度
    return metric[0] / metric[2], metric[1] / metric[2]

class Animator:  #@save
    """在动画中绘制数据"""
    def __init__(self, xlabel=None, ylabel=None, legend=None, xlim=None,
                 ylim=None, xscale='linear', yscale='linear',
                 fmts=('-', 'm--', 'g-.', 'r:'), nrows=1, ncols=1,
                 figsize=(3.5, 2.5)):
        # 增量地绘制多条线
        if legend is None:
            legend = []
        d2l.use_svg_display()
        self.fig, self.axes = d2l.plt.subplots(nrows, ncols, figsize=figsize)
        if nrows * ncols == 1:
            self.axes = [self.axes, ]
        # 使用lambda函数捕获参数
        self.config_axes = lambda: d2l.set_axes(
            self.axes[0], xlabel, ylabel, xlim, ylim, xscale, yscale, legend)
        self.X, self.Y, self.fmts = None, None, fmts

    def add(self, x, y):
        # 向图表中添加多个数据点
        if not hasattr(y, "__len__"):
            y = [y]
        n = len(y)
        if not hasattr(x, "__len__"):
            x = [x] * n
        if not self.X:
            self.X = [[] for _ in range(n)]
        if not self.Y:
            self.Y = [[] for _ in range(n)]
        for i, (a, b) in enumerate(zip(x, y)):
            if a is not None and b is not None:
                self.X[i].append(a)
                self.Y[i].append(b)
        self.axes[0].cla()
        for x, y, fmt in zip(self.X, self.Y, self.fmts):
            self.axes[0].plot(x, y, fmt)
        self.config_axes()
        display.display(self.fig)
        display.clear_output(wait=True)

def train_ch3(net, train_iter, test_iter, loss, num_epochs, updater):  #@save
    """训练模型（定义见第3章）"""
    animator = Animator(xlabel='epoch', xlim=[1, num_epochs], ylim=[0.3, 0.9],
                        legend=['train loss', 'train acc', 'test acc'])
    for epoch in range(num_epochs):
        train_metrics = train_epoch_ch3(net, train_iter, loss, updater)
        test_acc = evaluate_accuracy(net, test_iter)
        animator.add(epoch + 1, train_metrics + (test_acc,))
    train_loss, train_acc = train_metrics
    assert train_loss < 0.5, train_loss
    assert train_acc <= 1 and train_acc > 0.7, train_acc
    assert test_acc <= 1 and test_acc > 0.7, test_acc

lr = 0.1

def updater(batch_size):
    return d2l.sgd([W, b], lr, batch_size)

num_epochs = 10
train_ch3(net, train_iter, test_iter, cross_entropy, num_epochs, updater)

## 模型训练全流程（重要）
无论线性回归还是Softmax，训练流程都是统一的：
1. **数据准备**：读取数据，划分训练集/测试集，标准化（可选）
2. **模型定义**：用PyTorch的```nn.Linear```或自定义
3. **损失函数**：MSE（回归）/交叉熵（分类）
4. **优化器**：SGD/Adam
5. **训练循环**：```for epoch in range(num_epochs):```前向传播-->计算损失-->反向传播-->更新参数
6. **评估**：在测试集上计算损失或准确率
## 补充（来自实践和Github社区经验）
+ **特征标准化**：让每个特征的均值为0、方差为1，能显著加速收敛，用```sklearn.preprocessing.StandardScaler```
+ **学习率选择**：通常从0.01或0.001开始，如果损失震荡则调小，收敛太慢则调大
+ **Batch Size**：常见值32/64/128/256，取决于GPU显存
+ **初始化**：权重通常用```torch.nn.init.normal_```或```xavier```初始化，不要全零（会导致对称性问题）
+ **监控训练**：画出loss曲线，如果训练loss和验证loss差距过大，说明过拟合
