## 数据操作————张量
张量是深度学习中最基本的数据结构，可以理解为**多维数组**  
+ **标量（0维）**：单个数值，如```torch.tensor(3.0)```
+ **向量（1维）**：一维数组，如```torch.tensor([1,2,3])```
+ **矩阵（2维）**：二维数组，如```torch.tensor([1,2],[3,4])```
+ **高维张量（3维及以上）**：如图像数据通常为（批量大小，通道，高，宽）

+ **创建**：```torch.arange()``` ```torch.zeros()``` ```torch.ones()``` torch.randn()```
+ **索引**：```x[1:3,:]```切片操作
+ **形状**：```x.shape``` ```x.reshape()``` ```x.view()```
+ **拼接**：```torch.cat()``` ```torch.stack()```
+ **算术**：```+``` ```-``` ```*``` ```/``` ```**``` ```torch.exp()``` ```torch.matmul()```
+ **广播机制**：形状不同的张量自动扩展后运算

## 线性代数基础
+ **向量点积（内积）**： $x^\top y = \sum\limits_{i} x_i y_i$
+ **矩阵乘法**：**AB**，要求**A**的列数等于**B**的行数
+ **范数**：
  
  L2范数（欧几里得距离）：
  
$$\|x\|_2 = \sqrt{\sum_{i=1}^n x_i^2}$$

   L1范数（曼哈顿距离）： 
   
$$\|x\|_1 = \sum_{i=1}^n |x_i|$$

   矩阵范数(frobenius范数)：  
   
$$\|A\|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n a_{ij}^2}$$

## 微积分与梯度
+ **导数**：函数在某点的变化率
$$f'(x) = \lim\limits_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
+ **偏导数**：多变量函数对某一变量的导数，其余变量视为常数
+ **梯度**：将所有偏导数组成的向量
$$\nabla f(x) = \left[\dfrac{\partial f}{\partial x_1}, \dots, \dfrac{\partial f}{\partial x_n}\right]^\top$$
+ **链式法则**：复合函数求导
$$\dfrac{\mathrm{d}}{\mathrm{d}x} f(g(x)) = f'(g(x)) \cdot g'(x)$$
+ **梯度下降的核心思想**：沿着负梯度方向更新参数，使损失函数下降

## 自动微分
PyTorch的核心机制，自动计算梯度，省去手动推导的麻烦
+ **关键设置**：```x.requires_grad_(True)``` ```torch.tensor(...,requires_grad=True)
+ **反向传播**：```y.backward()```计算梯度，结果保存在```x.grad```中
+ **梯度清零**：```x.grad.zero_()```，否则梯度会累加
+ **分离计算图**：```y.detach()```用于需要数值但不需要梯度的场景
+ **控制流与梯度**：即使计算过程中有if/for等控制语句，PyTorch仍能正确计算梯度

## 线性代数知识体系
|知识点类别|关键概念|在深度学习中的主要应用|
|:---:|:---:|:---:|
|基础数据结构|标量、向量、矩阵、张量|数据的基本载体，张量是深度学习框架（PyTorch,TensorFlow）中的核心数据单元，图像、文本、音频都通过不同维度的张量表示|
|矩阵运算|矩阵乘法、转置、逆、伪逆|矩阵乘法是神经网络向前传播和反向传播的基本计算单元；伪逆用于求解最小二乘问题（如线性回归的闭式解）|
|特殊矩阵|对角矩阵、单位矩阵、对称矩阵、正交矩阵|对角矩阵便于计算（如某些正则化方法）；正交矩阵在参数初始化、某些循环神经网络（如正交RNN）和矩阵分解（如QR分解）中很重要|
|矩阵分解与核心概念|特征分解、奇异值分解、线性方程组、线性相关与生成子空间|SVD是主成分分析（PCA）和许多矩阵近似算法的基础；理解特征值和特征向量有助于理解线性变换的本质以及模型的稳定性|
|度量与计算|范数、行列式、迹运算|范数用来衡量向量或矩阵的大小，是正则化的基础；行列式衡量矩阵的“缩放效应”，在理解特征值和概密度变换时有用|
### 正交矩阵
#### 定义
一个正交矩阵Q是满足QT·Q=Q·QT=I的方阵，意味着QT=Q-1
#### 几何意义
一个**旋转或反射**，列（或行）向量是标准正交基，即两两内积为0（正交），且每个向量长度为1（单位化）
#### 关键性质
乘以正交矩阵不改变向量的L2范数（长度），即||Qx||2=||x||2。这使得它在数值计算中极其稳定，不会放大误差
#### 在深度学习中的具体用处
+ **参数初始化**：在训练深度网络（LSTM）时，用正交矩阵初始化权重，可以有效缓解梯度消失或爆炸问题，因为信号的范数在传播过程中得以保持
+ **PCA（主成分分析）**：PCA找到的“主成分方向”正是一个正交矩阵的列，它们构成了数据投影的新坐标轴
+ **对抗样本防御**：一些防御方法通过将输入或特征投影到正交空间来去除扰动
+ **梯度传播**：二维平面上的旋转矩阵将向量旋转但不改变其长度，在神经网络的梯度传播中非常有用
### 特征分解和奇异值分解
|分解方法|适用范围|数学形式|核心意义|
|特征分解|方阵|A=VΛV−1|把矩阵看成“沿特定方向（特征向量）进行缩放（特征值）”的操作|
|奇异值分解|任意矩阵|A=UΣVT|任何矩阵都可以看成“旋转--缩放--再旋转”三个步骤|
#### 特征分解
+ **应用例子**：图卷积网络（GCN）。GCN的核心是拉普拉斯矩阵的特征分解，特征向量作为“频率”基，用于在图上定义卷积操作。通过特征值可以分析图的连通性和平滑性。
+ **局限**：仅适用于方阵，且矩阵不一定总能对角化（需要n个线性无关的特征向量）
#### 奇异值分解
更通用的工具，几乎所有矩阵都能做SVD
+ **应用例子**：推荐系统（矩阵补全）。用户-物品评分矩阵R通常是稀疏的，通过SVD分解为UΣVT，取前K个最大的奇异值进行截断，就能得到降维后的低秩近似矩阵，用于预测用户对未评分的物品的喜好
+ **其他应用**：模型压缩，将大的权重矩阵W做SVD，用Uk​Σk​VkT​替代原矩阵，可以大幅度减少参数量（如ALBERT网络中的因子分解）
### SVD和矩阵近似算法
#### 矩阵近似算法
+ **核心思想**：用一个秩更低的、更简单的矩阵去逼近原始矩阵A，在损失一定精度的情况下，换取存储空间和计算速度的极大提升
#### SVD是实现矩阵近似的最强武器
+ **Eckart-Young定理**：对于任意给定的秩 r，截断奇异值分解（保留最大的 r 个奇异值及其对应的奇异向量）产生的矩阵 A~=UrΣrVrT​，在 L2 范数（或Frobenius范数）下，是所有秩为 r 的矩阵中对原矩阵 A 最好的近似。
+ **举个例子**：一张 1000×1000 的灰度图，原本需要存100万个像素值。如果对它做SVD，只保留前100个最大的奇异值（r=100），那么存储量变为 1000×100+100+1000×100≈20 万个数值，压缩了80%的大小，但肉眼看上去图片依然清晰。这就是**图像压缩算法的基础**。
### 范数和迹运算
#### 范数
一个将向量或矩阵映射为非负实数的函数
+ **向量范数**
+ **Frobenius范数**
+ **核范数**
#### 范数在深度学习中的核心用途：正则化（防止过拟合）
+ **L2正则化（权重衰减）**：在损失函数中加入所有权重的平方和，会迫使权重尽可能小，使模型函数变得更“平滑”，避免对训练数据中的噪声过拟合
+ **L1正则化（Lasso）**：加入绝对值之和，它将不重要的权重直接压缩为0，实现特征选择（稀疏性），用于模型剪枝
#### 迹运算：衡量总方差
迹是方阵对角线上所有元素之和，记作Tr(A)
**关键性质**：迹满足循环不变性Tr(ABC)=Tr(CAB)=Tr(BCA)，这在推导梯度时非常有用
#### 迹运算在深度学习中的具体用处
+ **衡量数据总方差**：在PCA中，协方差矩阵的迹等于数据在所有维度上的总方差。保留主成分时，可以通过比较迹的占比（Tr(近似协方差)/Tr(原协方差)​）来计算“信息保留百分比”
+ **简化梯度计算**：在推导Fisher信息矩阵或矩阵求导时，目标函数经常是矩阵的迹的形式。利用迹的循环性质，可以交换矩阵乘法顺序，大大简化梯度的链式求导过程。
+ **度量相似性**：在一些度量学习或图神经网络中，两个矩阵的点积（Frobenius内积）可以写成 ⟨A,B⟩=Tr(ATB)，用于衡量矩阵之间的相似度。
