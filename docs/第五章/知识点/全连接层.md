# 定义
**线性层**（Linear Layer）是神经网络中最基础、最常见的层之一
也常被称为**全连接层**（Fully Connected Layer，FC）或**稠密层**（Dense Layer）。

它的核心功能很简单：**对输入数据做一次线性变换**。

---

## 数学表达

假设输入是一个向量 \( x \)，线性层的计算是：

\[
y = xW^T + b
\]

其中：

- \( x \)：输入，形状为 \( ($N, d_{in}$) \)，\( N \) 是样本数，\( $d_{in}$ \) 是输入特征维度
- \( W \)：权重矩阵，形状为 \( ($d_{out}, d_{in})$ \)
- \( b \)：偏置向量，形状为 \( ($d_{out}$,) \)
- \( y \)：输出，形状为 \( (N, $d_{out}$) \)

用 PyTorch 举例：

```python
import torch.nn as nn

linear = nn.Linear(in_features=128, out_features=64)
# 输入 (batch_size, 128) -> 输出 (batch_size, 64)
```

---

## 直观理解

你可以把线性层看作一个**可学习的矩阵乘法 + 平移**：

1. **矩阵乘法**：把输入从一个维度空间投影到另一个维度空间
2. **加偏置**：给每个输出维度一个可学习的偏移量

比如输入是 128 维，输出是 64 维，线性层就学一个 \( 64 \times 128 \) 的矩阵，把 128 维向量压缩成 64 维。

---

## 为什么叫“线性”？

因为它只做线性变换。如果没有非线性激活函数，多层线性层堆叠起来仍然等价于一个线性层：

\[
W_2(W_1x) = (W_2W_1)x
\]

所以实际网络中，线性层后面通常会接 **ReLU、Sigmoid、GELU** 等非线性激活函数，才能让网络具备拟合复杂函数的能力。

---

## 常见用途

| 场景 | 作用 |
|------|------|
| CNN 分类头 | 把卷积提取的特征映射到类别数 |
| Transformer | 注意力机制中的 Q/K/V 投影、FFN 层 |
| 嵌入层之后 | 维度变换、特征融合 |
| 生成模型 | 把隐向量映射回数据空间 |

---

## 参数量

线性层的参数量是：

\[
d_{in} \times d_{out} + d_{out}
\]

例如 `nn.Linear(128, 64)` 有 \( 128 \times 64 + 64 = 8256 \) 个参数。

---

## 一句话总结

**线性层就是让神经网络学习一个仿射变换（矩阵乘法 + 偏置），用来改变特征维度、融合信息，是几乎所有神经网络的基础组件。**
