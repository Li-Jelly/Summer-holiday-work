## 具有单隐藏层的多层感知机

```
import torch
from torch import nn

net=nn.Sequential(nn.Linear(4,8),nn.ReLU(),nn.Linear(8,1))
X=torch.rand(size=(2,4))
net(X)
```
## 参数访问
把每一层里的权重拿出来
```
print(net[2].state_dict())
```
+ ```net[2]```是最后的一个输出层```nn.Linear(8,1)```
+ state：状态。从自动机的角度将，权重是一个状态，因为权重可以被改变
## 目标参数
直接访问某个具体的参数
```
print(type(net[2].bias))
print(net[2].bias)
print(net[2].bias.data)
```
```
<class'torch.nn.parameter.Parameter'>
Parameter containing:
tensor([-0.3389],requires_grad=True)
tensor([-0.3389])
```
+ net[2].bias是parameter中的一个可以修改的参数
+ 可以通过net[2].bias.data真正访问值
```
net[2].weight.grad==None
```
+ 通过net[2].weight.grad访问梯度
+ 此时还没有做反向计算，所以net[2].weight.grad==None，返回的是True
## 一次性访问所有参数
```
print(*[(name,param.shape)for name,param in net[0].names_parameters()])
print(*[(name,param.shape)for name,param in net.named_parameters()])
```
