## 具有单隐藏层的多层感知机

```
import torch
from torch import nn

net=nn.Sequential(nn.Linear(4,8),nn.ReLU(),nn.Linear(8,1))
X=torch.rand(size=(2,4))
net(X)
```
## 参数访问
把每一层里的权重拿出来
```
print(net[2].state_dict())
```
+ ```net[2]```是最后的一个输出层```nn.Linear(8,1)```
+ state：状态。从自动机的角度将，权重是一个状态，因为权重可以被改变

## 从嵌套块收集参数
```
def block1():
  return nn.Sequential(nn.Linear(4,8),nn.ReLU(),nn.Linear(8,4),
                       nn.ReLU())
def block2():
  net=nn.Sequential()
  for i in range(4):
    net.add_module(f'block{i}',block1())
  return net

rgnet=nn.Sequential(block2(),nn.Linear(4,1))
rgnet(X)
```
+ ```block1()```是一个```Sequential()```，三层网络
+ ```block2()```也是```Sequential()```，但是插入了四个```block1()```
+ ```add_module```可以传一个字符串的名字，可以明确是```block1()``` ```block2()```等等
+ 最后```rgnet```再在```block2()```外面嵌套一个```Sequential```
```
print(rgnet)
```
+ 用字符串的形式把rgnet打印出来

## 内置初始化（前面讲访问权重）
```
def init_normal(m):
  if type(m)==nn.Linear:
    nn.init.normal_(m.weight,mean=0,std=0.01)
    nn.init.zeros_(m.bias)

net.apply(init_normal)
net[0].weight.data[0],net[0].bias.data[0]
```
+ normal：正态分布函数
+ m：每次传入一个module
+ 如果这个module是线性层（全连接层）的话就执行if，不是的话就不做反应
  + 对weight做均值为0，方差为0.01的初始化（.noraml_下划线写在后面表示是它的替换函数，直接对参数进行替换，而不是返回一个值）
  + bias直接赋值为0
  + init.normal_和init.zeros_都在init Module中，init Module中包含了大量可以做初始化的函数
+ apply：遍历整个神经网络作为修改，cs中常用的函数API

```
def init_constant(m):
  if type(m)==nn.Linear:
    nn.init.constant_(m.weight,1)
    nn.init.zeros_(m.bias)

net.apply(init_constant)
net[0].weight.data[0],net[0].bias.data[0]
```
+ constant_：将weight全部赋值为1
  + 从API角度：可以这么做
  + 从算法角度：最好不要这么做，weight不能全部初始化为常数

```
def xavier(m):
  if type(m)==nn.Linear:
    nn.init.xavier_uniform_(m.weight)

def init_42(m):
  if type(m)==nn.Linear:
    nn.init.constant_(m.weight,42)

net[0].apply(xavier)
net[2].apply(init_42)
print(net[0].weight.data[0])
print(net[2].weight.data)
```
+ 用uniform_做xavier_对weight的初始化
+ constant_优化成常数（**“生命、宇宙以及一切事物的终极答案是什么？”--7500000 years ago “42！”**）
+ 假设有两个初始函数
  + 第一个用xavier初始化
  + 第二个用init_42初始化
+ network不管是里面的层还是外面的层，都是Module，可以对任何一个层调用apply这个函数
+ 对不同的层使用不同的初始化函数
```
def my_init(m):
  if type(m)==nn.Linear:
    print(
      "Init",
      *[(name,param.shape) for name,param in m.named_parameters()][0])
    nn.init.uniform_(m.weight,-10,10)
    m.weight.data*=m.weight.data.abs()>=5

net.apply(my_init)
net[0].weight[:2]
```
+ 自定义一个函数
  + 先print一下
  + 告诉名字，形状
  + 再均匀初始化
  + 自己乘自己绝对值是不是大于等于5
    + 是：保留
    + 不是：设为0
```
net[0].weight.data[:]+=1
net[0].weight.data[0,0]=42
net[0].weight.data[0]
```
+ 暴力做法
  + 所有值加1
  + 第一个值为42
  + 输出

## 参数绑定（小应用）
在一些层之间共享权重（两个数据流进来）
```
shared=nn.Linear(8,8)
net=nn.Sequential(nn.Linear(4,8),nn.ReLU(),shared,nn.ReLU(),shared,
                  nn.ReLU(),nn.Linear(8,1))
net(X)
print(net[2].weight.data[0]==net[4].weight.data[0])
net[2].weight.data[0,0]=100
print(net[2].weight.data[0]==net[4].weight.data[0])
```
+ 先把share的层构造出来，构造的时候就会把参数申请出来
+ 定义层的时候，第二层和第三层是share权重的，第一个和最后一个是自己的
+ 注意中间有ReLU
+ 更改其中一层，share的层也随之改变
