前面讲了怎么样自定义一个神经网络和访问参数，这节将怎么样自定义一个层
神经网络和层在这里没有区别，都是nn.Module的一个子类
---
## 构造一个没有任何参数的自定义层
```
import torch
import torch.nn.functional as F
from torch import nn

class CenteredLayer(nn.Module):
  def __init__(self):
    super().__init__()

  def forward(self,X):
    return X-X.mean()

layer=CenteredLayer()
layer(torch.FloatTensor([1,2,3,4,5]))
```
+ CenteredLayer没有参数，比较简单
+ init调用父类函数（不些会默认添加）
+ 跟自定义网络一样，定义forward函数
  + 输入减掉自己的均值，使得均值变成0
+ 用起来和自定义一个PyTorch的类或者Module一样
+ 定义类的实例
+ 把Tensor放进去

## 将层作为组件合并到构建更复杂的模型中
```
net=nn.Sequential(nn.Linear(8,128),CenteredLayer())

Y=net(torch.rand(4,8))
Y.mean()
```
+ 构建一个网络Sequential，把Linear放进去，把CenteredLayer（前面定义好的层）放进去
+ 实际输出的均值不会等于0，有浮点计算的误差

## 带参数的图层
```
class MyLinear(nn.Module):
  def __init__(self,in_units,units):
    super().__init__()
    self.weight=nn.Parameter(torch.randn(in_units,units))
    self.bias=nn.Parameter(torch.randn(units,))

  def forward(self,X):
    linear=torch.matmul(X,self.weight.data)+self.bias.data
    return F.relu(linear)

dense=MyLinear(5,3)
dense.weight
```
+ 之前参数都是Parameter类的实例，参数就调用相应的Parameter类
+ init函数定义一个自己的线性层
  + 一个输入的维度
  + 一个输出的维度
