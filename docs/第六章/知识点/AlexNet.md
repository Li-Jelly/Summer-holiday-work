## 深度学习之前的神经网络
### 机器学习
+ 特征提取
+ 选择核函数来计算相关性（在高维空间判断两个点是否相关）
  + 如果是线性就可以做内积
  + 如果用核方法，可以通过变换空间，把空间拉成我们想要的样子
+ 凸优化问题（比较热门的方向）
  + 有很好的理论结
  + 可以把显示节写出来
  + 有一套完整的泛函的定理
    + 可以很好地计算复杂度
    + 可以计算在什么样的情况下发生什么样的事情
+ 核方法有一段时间替代神经网络
+ SVM还是广泛使用（几乎不用调参）
### 几何学
+ 卷积神经网路
  + 2-D经常用在图片上（计算机视觉）
  + 计算机视觉是从几何学过来
+ 特征抽取
+ 描述几何（把计算机视觉问题描述成几何的问题）
  + 3个相机，通过相机的位置还原3-D
  + 如果有比较好的GPU
+ （非）凸优化
  + 如果有比较好的GPU模型，可以建立凸优化的目标函数，也可以建立非凸的
+ 漂亮定理
  + 凸优化
  + 或者特殊的非凸优化
+ 如果假设满足了，效果很好
  + 符合物理模型，效果就很好
  + 地球科学（气象预测）深度学习比做物理假设的效果更好
  + 药物研究
  + 材料学
### 特征工程（重要）
+ 一张图片怎么抽取特征（不要直接把原始效果拿进去）
+ 特征描述子：SIFT（抽取一些小向量来描述图片，之后再用一些多分类模型——SVM即可）,SURF
+ 视觉词带（聚类）
+ 最后用SVM
+ 关乎模型怎么更好地学习

## AlexNet
+ 在2012年拿到了ImageNet竞赛的冠军
+ 更大更深的LeNet
+ 主要改进：
  + 丢弃法（做模型的控制，模型更大了，做一些正则）
  + ReLU（Sigmoid改成了ReLU，在零点处一阶导更好一些，可以支撑更深的模型）
  + MaxPooling（输出比较大，梯度比较大，训练容易一些）
