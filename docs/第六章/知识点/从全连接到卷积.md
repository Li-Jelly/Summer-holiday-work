## 分类猫和狗的图片
+ 使用一个还不错的相机采集图片（12M——一千二百万像素）
+ RGB图片有36M元素（有R G B 三个通道）
  + 每个像素有一个值
+ 用单隐藏层的MLP训练，隐藏层大小是100，模型有3.6B（36亿）个元素
  + 远远多于世界上所有猫和狗的总数（900M——9亿只狗，600M——6亿只猫）

## 两个原则
+ 平移不变性
  + 识别器的识别不会因为图片像素位置的改变而导致识别结果改变
+ 局部性
  + 识别这个物体，只用看物体周围的信息即可
  + 不用识别全局的信息

## 具体怎么做
### 重新考察全连接层
怎么从上面两个原则出发，把全连接层应用到卷积 
+ 将输入和输出变形为矩阵（宽度，高度）
  + 之前拉平存成了向量
  + 这里有空间上的信息，要回归到矩阵来存
+ 将权重变形为4-D张量（h,w）到（h',w'）
  + 之前是一个输入的长度到输出的长度的变化
  + 现在是一个输入的高宽到一个输出的高宽的变化
  + 可以把形状reshape成一个4-D的张量
+二维情况：
<img width="194" height="58" alt="图片" src="https://github.com/user-attachments/assets/fd7b4a87-b812-4e50-873a-b7dcd69c5acc" />

+ 输入x可以看成一个超级无敌二维大矩阵，其中每个元素也是一个矩阵->四维

 $h_{i,j} = \sum_{k,l} w_{i,j,k,l} x_{k,l} = \sum_{a,b} v_{i,j,a,b} x_{i+a, j+b}$ 
  + $h_{i,j}$	输出特征图在位置 (i, j) 处的值
  + $Σ_{k,l}$	对输入的所有位置 (k, l) 求和
  + $w_{i,j,k,l}$	全连接形式的权重（依赖输出位置 i,j 和输入位置 k,l）
  + $x_{k,l}$	输入特征图在位置 (k, l) 处的值
  + $Σ_{a,b}$	对卷积核窗口内的相对位置 (a, b) 求和
  + $v_{i,j,a,b}$	卷积核权重（红笔标注的 w，即参数共享后的权重）
  + $x_{i+a, j+b}$	输入特征图在位置 (i+a, j+b) 处的值
+ 对w进行重排列（重新索引），记为v（下标进行变换）
  + 使得$v_{i,j,a,b} = w_{i,j,i+a,j+b}$
  + v是权重，也是识别图片的**识别器**

### 利用原则1：平移不变性
+ x的平移导致h的平移$h_{i,j} = \sum_{a,b} v_{i,j,a,b} x_{i+a,j+b}$
+ v不应该依赖于（i，j）
  + 解决方案：$v_{i,j,a,b} = v_{a,b}$
$h_{i,j} = \sum_{a,b} v_{a,b} x_{i+a,j+b}$
    + 前两个维度是不变的常熟，把前两个维度抹掉
    +  不管ij怎么变化，输出的位置变化，识别器都是不变的（v不变）
+ 一般叫“2维卷积”，在数学上是“二维交叉相关”
+ 输出是在对应像素（输入）为中心的小范围邻域内和v的内积
+ 平移不变性：对权重做了限制，把v的ij维抹掉了，只剩ab维度
+ 二维卷积可以看成一个全连接/矩阵乘法，但是它的权重使得某些部分是重复的，不是每个元素都可以自由变换
+ 把一个模型的取值范围做了限制，这个模型的复杂度就降低了，不用存那么多元素了

### 利用原则2：局部性
输出不应该看以输入为中心的一个大邻域，看一个小的邻域就行了
+ 当评估h_ij时，不应该用远离x_ij的参数
+ 解决方案：当|a|,|b|>Δ时，使得v_ab=0
$h_{i,j} = \sum_{a=-\Delta}^{\Delta} \sum_{b=-\Delta}^{\Delta} v_{a,b} x_{i+a,j+b}$
  + a表示在宽度上
  + b表示在长度上
