## 互相关运算
```
import torch
from torch import nn
from d2l import torch as d2l

def corr2d(X,K):
  """计算二维互相关运算。"""
  h,w=K.shape
  Y=torch.zeros((X.shape[0]-h+1,X.shape[1]-w+1))
  for i in range(Y.shape[0]):
    for j in range(Y.shape[1]):
      Y[i,j]=(X[i:i+h,j:j+w]*K).sum()
  return Y
```
+ X：输入
+ K：核矩阵
+ h：行数
+ w：列数
+ 输出的高度=输入的高度-核矩阵的高度+1
+ 输出的宽度=输出的高度-核矩阵的高度+1
+ 所看区域：
  + 第i行开始，往后h行
  + 第j列开始，往后w列
+ 和核矩阵做点积求和（两个形状相同）

## 验证上述二维互相关运算的输出

## 学习由X生成Y的卷积核
+ 给定X（输入）
+ 给定Y（输出）
+ 学习中间的核
```
conv2d=nn.Conv2d(1,1,kernel_size=(1,2),bias=False)

X=X.reshape((1,1,6,8))
Y=Y.reshape((1,1,6,7))

for i in range(10):
  Y_hat=conv2d(X)
  l=(Y_hat-Y)**2
  conv2d.zero_grad()
  l.sum().backward()
  conv2d.weight.data[:]-=3e-2*conv2d.weight.grad
  if(i+1)%2==0:
    print(f'batch{i+1},loss{l.sum():3f}')
```
+ 这里直接调用了PyTorch.nn的Conv2d的定义，和之前自己写的差不多
+ 前面两个1（一个是通道维度，一个是批量大小维度）：
  + 输入了通道（输入是1，输出也是1）
  + 黑白图片通道为1
  + 彩色图片通道为3
+ 1*2的核
+ 不需要bias，bias=False
+ X,Y。reshape：加通道维度和批量大小维度
  + 对所有Conv2d来说，都是一个4-D的东西（通道数，批量大小数，行数，列数）
+ 手写了一个训练逻辑（这里是一个梯度下降）：
  + 迭代10轮：
    + 每次把X放进conv2d中，得到一个y_hat
    + 用均方误差（(Y_hat-Y)**2）得到的值作为loss
    + 把conv2d的梯度设成0
    + loss求和，反向传播
    + 学习率是3e-2
    + 做了.backward()之后，weight.grad就可以得到梯度
    + 每两个小批量（batch）之后，就print一下loss
