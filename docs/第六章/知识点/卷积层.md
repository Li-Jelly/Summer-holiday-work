## 二维卷积层
<img width="823" height="462" alt="图片" src="https://github.com/user-attachments/assets/53f55441-08c9-4c48-8f48-4103ae70d282" />

+ 输入X：$n_h \times n_w$（高乘宽）
+ 核W：$k_h \times k_w$（高乘宽）
+ 偏差$b \in \mathbb{R}$（很简单的一个实数）
+ 输出Y：$(n_h - k_h + 1) \times (n_w - k_w + 1)$
  + 输出会变小，2*2在3*#上最多移一次
  + 丢掉的就是k_h-1和k_w-1
$\mathbf{Y} = \mathbf{X} \star \mathbf{W} + b$
+ $\star$：二维交叉操作子
+ W和b是可学习的参数

## 交叉相关vs卷积
+ 二维交叉相关
$y_{i,j} = \sum_{a=1}^{h} \sum_{b=1}^{w} w_{a,b} x_{i+a, j+b}$
+ 二维卷积
$y_{i,j} = \sum_{a=1}^{h} \sum_{b=1}^{w} w_{-a,-b} x_{i+a, j+b}$
  + 卷积在索引w的时候是镜像的（ab前面有负号）
+ 由于对称性，在实际使用中没有区别
  + w是学习出来的，图形本身不改变，只要反射一下就行
 
## 一维和三维交叉相关
+ 一维
  + 文本（CNN也可以做文本）
  + 语言
  + 时序序列
$y_i = \sum_{a=1}^{h} w_a x_{i+a}$
+ 二维
  + 图片（图片主流用二维）
$y_{i,j} = \sum_{a=1}^{h} \sum_{b=1}^{w} w_{a,b} x_{i+a, j+b}$
+ 三维
  + 视频（时间）
  + 医学图像（分层）
  + 气象地图（时间）
$y_{i,j,k} = \sum_{a=1}^{h} \sum_{b=1}^{w} \sum_{c=1}^{d} w_{a,b,c} x_{i+a, j+b, k+c}$

## 总结
+ 卷积层将输入和和矩阵进行交叉相关，加上偏移后得到输出
+ 核矩阵和偏移是可学习的参数
+ 核矩阵的大小是超参数（控制局部性）
  + 不管输入有多大
  + 如果就是要看一个3*3的局部信息的话
  + **权重个数不会随着输入个数的变大而变大**
+ 卷积层是一个特殊的全连接层
  + 做成4-D之后，前面两个维度一样
  + 局部来看
