## 填充
在输入比较小的时候使用
+ 给定（32*32）输入图像
+ 应用5*5大小的卷积核
  + 第一层得到输出大小28*28
  + 第7层得到输出大小4*4
+ 更大的卷积核可以更快地减小输出大小
  + 形状$n_h*n_w$减少到（$(n_h-k_h+1)*(n_w-k_w+1)$）
+ 用了5/*5，输出就会减少4/*4
+ 假设不想让输出太小（想用比较大地卷积核）或者想做更深的模型
  + 用填充

填充
+ 在输入的周围添加额外的行/列
+ 让输出比以前更大
<img width="817" height="439" alt="图片" src="https://github.com/user-attachments/assets/453933cd-961c-40ca-877f-9e527a68de32" />

+ 在最外围添加了0
+ 输出从2/*2变到了4/*4
<img width="810" height="445" alt="图片" src="https://github.com/user-attachments/assets/c9ec4a77-2ea0-448a-ac2a-31ff6ec51af3" />

+ 填充p_h行和p_w列，输出形状为$(n_h - k_h + p_h + 1) \times (n_w - k_w + p_w + 1)$
+ 通常取$p_h = k_h - 1, \quad p_w = k_w - 1$(核的高宽减-1)
  + 此时输出为n_h*n_w（输出和输入形状相同）**且和核的大小无关**（用多大多小的核都不会改变输出的形状）
  + 当k_h为奇数：在上下两侧填充p_h/2
  + 当k_h为奇数：在上侧填充[p_h/2]（上取整），在下侧填充[p_h/2]（下取整）（上测多一行，下侧少一行）
  + 填充值一般取0
 
## 步幅
在输入比较大的时候使用（可以用比较大的卷积核减少层数，但是一般会用比较小的卷积核）
+ 填充减小的输出大小与层数线性相关
  + 给定输入大小224/*224，在使用5/*5卷积核的情况下，需要44层将输出降低到4/*4
  + 需要大量计算才能得到较小输出（层数越多，计算越复杂）
+ 之前输出的大小和层数线性相关
+ 现在输出的大小和层数指数相关

步幅
+ 步幅是指行/列的滑动步长（在输入上不是一行一行移动，且高和宽可以移动不一样距离）

+ 在输入后面可能会加**步幅**的高和宽（如果不够）
+ 输出大小除以**步幅**的高和宽
+ 还有一个往下取整
+ 如果输入的高度和宽度都可以被**步幅**整除
  + 这个情况很常见
  + 因为步幅多取2，只要宽高为偶数，就能整除

## 总结
+ 填充和步幅是卷积层的超参数
+ 填充在输入周围添加额外的行/列，来控制输出形状的减少量
  + 输入比较小
  + 不想让卷积层减少输出
  + 填充让输出至少不变，或者变大
  + 不想用过大的卷积核让网络加深
  
+ 步幅是每次滑动核窗口的行/列的步长，可以成倍的减少输出形状
  + 输入大小比较大
  + 通过步幅将输出的大小成倍地往下减
  + 从而减少计算量
