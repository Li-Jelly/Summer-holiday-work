## 池化层
+ 卷积层对位置敏感
  + 检测垂直边缘
  + 图片的边缘可能不一定正好出现在那么“正”的位置上
+ 需要一定程度的平移不变性
  + 照明，物体位置，比例，外观等等因图像而异
  + 物体在有一些变化的情况下，在这个地方该输出1还是输出1
  + 太剧烈的变化会让其对位置太敏感

## 二维最大池化层
+ 返回滑动窗口中的最大值
  + 池化层没有核
  + 不是输入和核做加权和
  + 而是在规定大小（2*2）的窗口中，寻找输入的最大值（最大池化层）并返回
<img width="814" height="453" alt="图片" src="https://github.com/user-attachments/assets/c94aee6e-c350-4305-946c-ae91e965de21" />

+ 2*2池化层：可容1位像素移位（右侧移到左侧，还是可以检出边缘
+ 有一点模糊化的效果
  + 在输出值附近的小窗口使得它的值都会出现
 
## 填充，步幅，多个通道
+ 池化层与卷积层类似，都具有填充和步幅
+ 没有可学习的参数
+ 在每个输入通道应用池化层以获得相应的输出通道
  + 对每个输入通道做一次池化，得到对应的输出通道
  + 不像卷积一样，可以融合多输入通道
  + 多通道融合可以交给卷积层来做
+ 输出通道数=输入通道数

## 平均池化层
+ 最大池化层：每个窗口中最强的模式信号
  + 输出每个窗口最强的信号，比较亮，有一些比较明显的层化信息
+ 平均池化层：将最大池化层中的“最大”操作替换为“平均操作”
  + 有一个比较柔和化的效果
  + 用平均操作子（.max()->.mean()）

## 总结
+ 池化层返回窗口中最大或平均值
+ 缓解卷积层对位置的敏感性
+ 同样有窗口大小、填充、步幅作为超参数
+ 对每个通道，分别作用，直接输出，不进行融合
+ 没有输出通道数这个超参数（输出通道数等于输入通道数，输入通道数是上一层的输出通道超参数）
  + 输出通道数=输入通道数
  + 池化层不会把模型变大
+ 没有可以学习的参数

 ## 代码实现
### 实现池化层的正向传播
```
import torch
from torch import nn
from d2l import torch as d2l

def pool2d(X,pool_size,mode='max'):
  p_h,p_w=pool_size
  Y=torch.zeros(X.shape[0]-p_h+1,X.shape[1]-p_w+1)
  for i in range(Y.shape[0]):
    for j in range(Y.shape[1]):
      if mode=='max':
        Y[i,j]=X[i:i+p_h,j:j+p_w].max()
      else mode=='avg':
        Y[i,j]=X[i:i+p_h,j:j+p_w].mean()
  return Y
```
+ p_h,p_w：池化窗口的高和宽
+ 创建输出（假设单通道）
  + 输入的高-窗口的高+1
  + 输入的宽-窗口的宽+1
+ 两个迭代
  + 先每行迭代
  + 后每列迭代

### 填充和步幅可以手动设定
```
pool2d=nn.MaxPool2d(3,padding=1,stride=2)
pool2d(X)
```
+ stride：步幅
+ padding：填充
