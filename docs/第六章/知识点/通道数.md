  ## 1*1卷积层
  + 卷积核的高和宽都等于1
  + 它不识别空间模式，只融合通道
    + 每次只看一个像素，不看周围的信息
    + 只融合不同通道的信息
    + 相当于同一位置不同输入通道的信息（借助对应通道卷积核）做加权和
  + 相当于输入形状为n_hn_w*c_i，权重为c_o*c_i的全连接层
    + 把每个通道的输入拉成一个向量，核为对应输出通道内对应输入通道，高宽都为1

## 二维卷积层在通用情况下的样子
+ 每个输入通道和每个输出通道都有一个标量的偏差
+ 计算复杂度：
  + 输入输出的通道数
  + 核的高和宽
  + 输出的高和宽
  + 1G（10亿）浮点运算
  + 如果有10层这样的卷积层，100万（1M）个样本，就有10P浮点运算
    + 不做反向
    + 做反向要翻倍
    + CPU：0.15TF=18h
    + GPU：12TF=14min
  + 卷积层计算时间不低
  + 模型存储比较小
    + 100*100*5*5的小的4-D张量

## 总结
+ 输出通道数是卷积层的超参数（输入是前一层的输出的超参数）
+ 每个输入通道有独立的二维卷积核，所有通道结果相加得到一个输出通道结果
+ 每个输出通道有独立的三维卷积核

## 代码实现
### 实现一下多输入通道互相关运算
```
import torch
from d2l import torch as d2l

def corr2d_multi_in(X,K)
  return sum(d2l.corr2d(x,k) for x, k in zip(X,K))
```
+ corr2d_multi_in：2d互相关运算，处理多个通道
+ zip：对输入通道做遍历
### 验证互相关运算的输出

```
def corr2d_multi_in_out(X,K):
  return torch.stack([corr2d_multi_in(X,k) for k in K],0)

K=torch.stack((K,K+1,K+2),0)
K.shape
```

+ K之前是3-D，现在创建K，K+1，K+2通道（在0的维度上stack起来）

### 1*1卷积
1*1的卷积等价于一个全连接
```
def corr2d_multi_in_out_lxl(X,K):
  c_i,h,w=X.shape
  c_o=K.shape[0]
  X=X.reshape((c_i,h*w))
  K=K.reshape((c_o,c_i))
  Y=torch.matmul(K,X)
  return Y.reshape((c_o,h,w))

X=torch.normal(0,1,(3,3,3))
K=torch.nomal(0,1,(2,3,1,1))

Y1=corr2d_multi_in_out_lxl(X,K)
Y2=corr2d_multi_in_out(X,K)
assert float(torch.abs(Y1-Y2).sum())<1e-6
```
+ 这里X和K都成一个2*2的矩阵了
+ 直接调用矩阵乘法
+ （输出通道，输入通道，高，宽）
+ Y1是全连接层
+ Y2是1*1卷积
+ Y1=Y2（相减绝对值的求和小于1e-6，有浮点运算的误差）
