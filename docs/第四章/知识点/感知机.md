## 感知机
### 定义
感知机是人工智能领域最早的监督学习算法之一，由Frank Rosenblatt在1958年提出，它在结构上是一个单层的神经网络，本质是一个**二元线性分类器**
### 核心逻辑
+ **输入**：多个数值特征（x1,x2,...,xn）
+ **计算**：每个输入乘以对应的权重（w），加上一个偏置（b），求和。
$z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$
+ **激活**：将求和结果 z 放入一个阶跃函数（符号函数）。如果 z>0，输出 +1（代表一类）；如果 z≤0，输出 -1或0（代表另一类）

### 二分类
+ Vs.回归输出实数
+ Vs.Softmax回归输出概率（输出n个元素，多分类问题）
### 训练感知机
```
initialize w=0 and b=0
repeat
  if yi[<w,xi>+b]<=0 then
    w<-w+yixi and b<-b+yi
  end if
until all classified correctly
```
#### 第一步：符号说明
| 符号 | 含义 |
|------|------|
| `w` | 权重向量（分类直线的斜率/方向） |
| `b` | 偏置（分类直线的截距） |
| `xᵢ` | 第 i 个样本的特征向量（平面上的一个点） |
| `yᵢ` | 第 i 个样本的真实标签，取值只能是 +1 或 -1（两个类别） |
| `⟨w, xᵢ⟩` | 向量点积，代表 w 和 xᵢ 的相似度 |

点积<w,xi>的大小和正负完美地刻画了向量xi在向量w方向上地**投影长度**，而“投影长度”正是判断两个向量“方向是否一致”的度量标准，也就是“相似度”  
##### 从几何角度看
$\langle w, x_i \rangle = \|w\| \times \|x_i\| \times \cos \theta$
+ 当角度为0（方向完全一致）：点积取得**最大正值**，非常相似
+ 当角度为90（方向垂直）：点积为0，无关，不相似
+ 当角度为180（方向完全相反）：点积取得**最大负值**，极度不相似（相反）  
点积的正负号直接代表xi是朝着w的方向，还是背着w的方向，这正是分类器需要的——用正负号来区分两个类别
##### 从代数计算看
+ 如果我们把w看作一个**固定的“法向量”（即分类直线的垂线）**，那么<w,xi>实际上就是把xi投影到w这条直线上的**带符号长度**  
+ **关键点**：在感知机里，我们加上偏置 b，得到 ⟨w,xi​⟩+b，这个整体其实就是**点xi到分类决策面（直线/超平面）的“带符号距离”**
  + 距离>0：点在直线的一侧（预测+1）
  + 距离=0：点正好在直线上
  + 距离<0：点在直线的另一侧（预测-1）
##### 为什么说是相似度
+ 是**自然语言处理（NLP）和推荐系统**里的习惯说法，这些场景里w和xi都是**单位向量**（或者长度固定），此时：
$\langle w, x_i \rangle = \cos \theta$
这时候点积的值域就是 [−1,1] ，直接等于夹角余弦值，完美地代表相似度
+ 但在感知机里，w 的长度是随着训练不断变化的，所以点积的值并不限制在 [-1, 1] 之间。它更多代表的是“方向和距离的综合度量”。不过，因为正负号依然能反映方向是否一致，所以很多老师为了降低初学者的理解门槛，会模糊地说“代表相似度”。
#### 第二步：核心条件判断
$y_i \left[ \langle w, x_i \rangle + b \right] \leq 0$
这是整个算法的“犯错检测器”
+ <w,xi>+b是模型对样本xi的原始打分，如果打分>0，模型预测其为+1类；打分<0，预测为-1类
+ 用这个打分**乘以真实的yi**:

| 真实标签 \( y_i \) | 模型打分符号 sign(\( f \)) | 是否同号? | 乘积 \( y_i \cdot f \) | 判定结果 | 含义 |
|---|---|---|---|---|---|
| +1 | +1 | ✅ 是（同号） | > 0 | 正确 | 正确，且非常安全 |
| -1 | -1 | ✅ 是（同号） | > 0 | 正确 | 正确，但不自信（仍需优化） |
| +1 | -1 | ❌ 否（异号） | < 0 | 错误 | 犯错，且离边界较远 |
| -1 | +1 | ❌ 否（异号） | < 0 | 错误 | 犯错，靠边界较近 |
| 任意 | 0 | —（无符号） | = 0 | 边界（算错误） | 恰好在边界上，算犯错（损失 = 1），需要调整 |

#### 第三步：如果犯错了怎么改
+ **情况1**：真实是+1，但预测为-1
  + 此时yi=+1
  + 更新：w=w+（+1）*xi 把w往xi方向拉近
  + b=b+（+1） 把偏置往正向调整
  + 效果：下次再见到这个样本，打分<w,xi>+b会变大，更容易变成正数，从而分对
+ **情况2**：真实是-1，但预测为+1
  + 此时yi=-1
  + 更新：w=w+（-1）*xi 把w往xi的反方向推
  + b=b+(-1) 把偏置往负方向调
  + 效果：下次再见到这个样本，打分<w,xi>+b会变小，更容易变成负数，从而分对
**总结**：每次犯错，就把分类直线（超平面）往“分错这个点”的方向拽一把，直到所有点都站到对边为止

#### 第四步：为什么等价于批量大小为1的梯度下降
合页损失函数：
$\ell(y, x, w) = \max(0, -y\langle w, x\rangle)$
+ 当分类正确且自信（y<w,x> >0）时，损失=0，不更新
+ 当分类错误（y<w,x> <0）时，损失=-y<w,x>，是一个正数
+ max对应if语句

对损失函数求关于w的梯度：
$\frac{\partial \ell}{\partial w} = -y \cdot x$
使用梯度下降更新权重（学习率为1）：
$w = w - \text{学习率} \times \text{梯度} = w - 1 \times (-yx) = w + yx$
和上面的更新公式完全一样
**总结**：每次只拿一个样本（批量大小为1）来计算梯度，然后更新一次，这就是随机梯度下降(SGD)的最原始形态（感知机最原始的模型是一遍一遍扫数据，没有随机初始值）

### 收敛定理
+ 数据在半径r内
+ 余量ρ分类两类
$y(\mathbf{x}^\top \mathbf{w} + b) \geq \rho$
对于 $\| \mathbf{w} \|^2 + b^2 \leq 1$
+ 感知机保证在 $\frac{r^2 + 1}{\rho^2}$ 步后收敛
#### 作用
+ **问题**：如果反复用感知机算法纠正错误，要多久才能把所有点都分对
+ **回答**：只要数据是线性可分的，它保证在有限步内收敛，并且这个步数有一个明确的上限
#### 前提条件
1. **数据在半径r内**
所有数据点x离原点的距离都不超过r，即||x||<=r，这保证数据不是无限分的，是有界的
2. **余量ρ分类两类**和公式 $y(x^T w + b) \geq \rho$
**存在一条完美的分类直线（超平面），不仅能把所有点分对，而且所有点都离这条直线至少ρ那么远**
+ 这里的w和b是那条“理想完美直线”的参数（不是训练中训练的那个）
+ ρ越大，说明两类数据分得越开，问题越简单
3. 对于 $\|w\|^2 + b^2 \leq 1$
这是那条完美直线的约束，限制它的参数不能无限过大，简单理解就是把那条完美分界线归一化了，使得它的“斜率”和“截距”被控制在一个标准单位内
#### 结论
算法在一定步数后一定能收敛：
步数 ≤ $\frac{r^2 + 1}{\rho^2}$
+ 分子 ${r^2 + 1}$ ：代表**数据的分散程度**，数据点离原点越远（r越大），或者数据维度越高（隐含在+1里），需要的调整步数就越多
+ 分母 ${\rho^2}$ ：代表**分类的难易程度**，两类数据靠得越近，安全余量越小，算法就需要花更多次数去反复试探、修正；如果两类数据离得特别远，那算法可能扫几遍数据就搞定了

## 多层感知机（MLP）
### 定义
多层感知机是由**输入层、一个或多个隐藏层、输出层**组成的全连接前馈神经网络
### 核心提升
+ **隐藏层**：在输入和输出之间加入了若干层神经元，这些层不直接与外界交互，负责提取和组合高阶特征
+ **非线性激活函数**：MLP不再使用阶跃函数，而是使用Sigmoid、Tanh或ReLU等连续平滑的非线性函数
  + 加入了**非线性激活函数**，多层感知机不再是简单的线性组合，根据通用近似定理，一个拥有至少一个隐藏层和足够多神经元的MLP，可以以任意精度逼近任何**连续函数**，即MLP可以解决线性不可分的问题（比如异或问题），这也是它被称为“万能函数拟合器”的原因
### 学习XOR问题
**这个地方的正负号不一定按照数学的象限给定！！！**
+ 在蓝色线左边为正，右边为负
+ 在黄色线上边为正，下边为负
+ 蓝色和黄色的结果都为正或负，则正；蓝色和黄色的结果不同，则负

### 单隐藏层
#### 超参数
**在机器学习开始前，由人工设定好的“旋钮”或“开关”**，而不是通过数据训练学出来的参数
+ **模型参数**：“学到的知识”
+ **超参数**：“输入的指定值”
  + **学习率**：决定模型“吸收”错误的速度，太大容易学过头（翻车），太小学得太慢（急死人）
  + **批量大小**：一次性喂给模型多少条数据去计算
  + **迭代轮数**：把整个数据集从头到尾学多少遍
  + **网络层数**：决定模型的“脑容量”有多大
**核心难点**：超参数没有标准答案，不同数据需要不同的设置。所以数据科学家常做的“调参”，其实就是反复试验
+ **超在哪里**
  + **层级“超”于模型之上（位置高）**：模型参数（权重、偏置）是模型内部的东西，由数据自动算出。而超参数是模型外部的指令，用来指挥“如何算出”那些内部参数。它在架构层级上高于模型，所以叫“超”
  + **作用“超”越单次训练（范围广）**：模型参数只属于这一次训练的结果，换一批数据就得重学。但超参数（比如学习率、网络层数）一旦定下来，就定义了整个训练策略，它控制着参数更新的全过程，影响范围覆盖所有参数
  + **来源“超”脱数据（非自动）**：模型参数来源于数据统计（从数据中“生长”出来），而超参数来源于人的经验或暴力搜索（调参）。它不是数据告诉你的，而是在数据之外“空降”的指令

## 多层感知机的从零开始实现
### 准备工作
```
import torch
from torch import nn
from d2l import torch as d2l

batch_size = 256
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
```
### 初始化模型参数
```
num_inputs, num_outputs, num_hiddens = 784, 10, 256

W1 = nn.Parameter(torch.randn(
    num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))
W2 = nn.Parameter(torch.randn(
    num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]
```
### 激活函数
```
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)
```
### 模型
```
def net(X):
    X = X.reshape((-1, num_inputs))
    H = relu(X@W1 + b1)  # 这里“@”代表矩阵乘法
    return (H@W2 + b2)
```
### 损失函数
```
loss = nn.CrossEntropyLoss(reduction='none')
```
### 训练
```
num_epochs, lr = 10, 0.1
updater = torch.optim.SGD(params, lr=lr)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
```
```
d2l.predict_ch3(net, test_iter)
```
