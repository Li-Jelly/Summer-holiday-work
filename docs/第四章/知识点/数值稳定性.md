### 1. 神经网络的梯度
#### 公式一
$\mathbf{h}^t = f_t(\mathbf{h}^{t-1}) \quad \text{and} \quad y = \ell \circ f_d \circ \dots \circ f_1(\mathbf{x})$
+ 描述的是深度学习中**序列模型**（如RNN）和**前馈神经网络**的基本计算过程
+ 循环神经网络（RNN）的隐状态更新公式  
$\mathbf{h}^t = f_t(\mathbf{h}^{t-1})$
  + $\mathbf{h}^t$ ：第t个时间步的**隐状态**（hidden state），是一个向量，承载了到时刻t为止的历史信息
  + $\mathbf{h}^{t-1}$ ：上一时间步的隐状态
  + $f_t$ ：第t步的**状态转移函数**（通常是一个带参数的神经网络层，如 $f_t(\mathbf{h}) = \tanh(W\mathbf{h} + U\mathbf{x}^t + b)$ ）
  + **含义**：当前时刻的隐状态只由上一时刻的隐状态决定（马尔可夫性质），函数 $f_t$ 在不同时间步可以相同 （标准RNN）或不同（如LSTM的门控结构）  
$y = \ell \circ f_d \circ \dots \circ f_1(\mathbf{x})$
这是**多层前馈网络（或深度网络的整体映射）** 的复合函数表示
+ x：输入
+ $f_1,f_2,...,f_d$ ：：第1到第d层的**变换函数**（每层通常为线性变换+非线性激活）
+ $\circ$ ：**函数符合运算符**，即 $(g \circ f)(x) = g(f(x))$
+ l：**输出层/损失函数**，（如softmax分类头，或损失函数）
+ **含义**：输入x依次经过 $f_1,f_2,...f_d$ 逐层变换，最后经l得到输出y，展开写就是：  
$y = \ell(f_d(\dots f_2(f_1(\mathbf{x})) \dots))$  
##### 两者的联系
这两个公式常一起出现，用来描述**带循环结构的深度序列模型**：
1. 公式一在**时间维度**上递归： $\mathbf{h}^1 \rightarrow \mathbf{h}^2 \rightarrow \cdots \rightarrow \mathbf{h}^T$
2. 公式二在**深度维度**上复合： $f_1 \rightarrow f_2 \rightarrow \cdots \rightarrow f_d$
如果把RNN按时间步展开（unroll），其实就是一个**深度为T、各层共享的深层网络**，此时两个公式本质上是统一的——一个沿时间展开，一个沿层展开
+ 公式一：**当前隐状态由上一隐状态决定（时间递归）**
+ 公式二：**输出是输入经过多层函数复合后的结果（深度复合）**
两者共同刻画了深度序列模型“**沿时间递归+沿层复合**”的计算结构
