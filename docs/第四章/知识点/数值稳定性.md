## 数值稳定性（机器学习中很重要）
当神经网络很深的时候，数值不稳定
### 1. 神经网络的梯度
#### 公式一
$\mathbf{h}^t = f_t(\mathbf{h}^{t-1}) \quad \text{and} \quad y = \ell \circ f_d \circ \dots \circ f_1(\mathbf{x})$
+ t表示层
+ l表示损失函数（要优化的目标函数）
+ y不是预测，还包括了要优化的损失函数
+ 描述的是深度学习中**序列模型**（如RNN）和**前馈神经网络**的基本计算过程
+ 循环神经网络（RNN）的隐状态更新公式  
$\mathbf{h}^t = f_t(\mathbf{h}^{t-1})$
  + $\mathbf{h}^t$ ：第t个时间步的**隐状态**（hidden state），是一个向量，承载了到时刻t为止的历史信息
  + $\mathbf{h}^{t-1}$ ：上一时间步的隐状态
  + $f_t$ ：第t步的**状态转移函数**（通常是一个带参数的神经网络层，如 $f_t(\mathbf{h}) = \tanh(W\mathbf{h} + U\mathbf{x}^t + b)$ ）
  + **含义**：当前时刻的隐状态只由上一时刻的隐状态决定（马尔可夫性质），函数 $f_t$ 在不同时间步可以相同 （标准RNN）或不同（如LSTM的门控结构）
#### 公式二
$y = \ell \circ f_d \circ \dots \circ f_1(\mathbf{x})$
这是**多层前馈网络（或深度网络的整体映射）** 的复合函数表示
+ x：输入
+ $f_1,f_2,...,f_d$ ：：第1到第d层的**变换函数**（每层通常为线性变换+非线性激活）
+ $\circ$ ：**函数符合运算符**，即 $(g \circ f)(x) = g(f(x))$
+ l：**输出层/损失函数**，（如softmax分类头，或损失函数）
+ **含义**：输入x依次经过 $f_1,f_2,...f_d$ 逐层变换，最后经l得到输出y，展开写就是：  
$y = \ell(f_d(\dots f_2(f_1(\mathbf{x})) \dots))$  
##### 两者的联系
这两个公式常一起出现，用来描述**带循环结构的深度序列模型**：
1. 公式一在**时间维度**上递归： $\mathbf{h}^1 \rightarrow \mathbf{h}^2 \rightarrow \cdots \rightarrow \mathbf{h}^T$
2. 公式二在**深度维度**上复合： $f_1 \rightarrow f_2 \rightarrow \cdots \rightarrow f_d$
如果把RNN按时间步展开（unroll），其实就是一个**深度为T、各层共享的深层网络**，此时两个公式本质上是统一的——一个沿时间展开，一个沿层展开
+ 公式一：**当前隐状态由上一隐状态决定（时间递归）**
+ 公式二：**输出是输入经过多层函数复合后的结果（深度复合）**
两者共同刻画了深度序列模型“**沿时间递归+沿层复合**”的计算结构
#### 计算损失l关于Wt的梯度
$\frac{\partial \ell}{\partial \mathbf{W}^t} = \frac{\partial \ell}{\partial \mathbf{h}^d} \frac{\partial \mathbf{h}^d}{\partial \mathbf{h}^{d-1}} \cdots \frac{\partial \mathbf{h}^{t+1}}{\partial \mathbf{h}^t} \frac{\partial \mathbf{h}^t}{\partial \mathbf{W}^t}$
##### 深度学习中反向传播（Backpropagation）的链式法则
+ 在计算损失函数对某个特定层权重Wt的梯度
+ 通常出现在**循环神经网络（RNN）的随时间反向传播（BPTT，Backpropagation Through Time）**中
  + t表示时间步，d代表总的时间步数（或总层数）
**损失函数 ℓ 对第 t 步（或第 t 层）权重 Wt 的梯度**，等于从最终输出层（第 d 步）的梯度，一路“反向”传播回第 t 步的梯度，最后再乘以第 t 步隐状态对权重的偏导。
  + $\frac{\partial \ell}{\partial \mathbf{h}^d}$ ：损失函数对最终隐状态（或输出）的梯度。这里是反向传播的**起点**
  + $\frac{\partial \mathbf{h}^d}{\partial \mathbf{h}^{d-1}} \cdots \frac{\partial \mathbf{h}^{t+1}}{\partial \mathbf{h}^t}$ ：这是一系列**雅可比矩阵**相乘。它表示误差信号从第d步一步步传回第t步的过程
  + $\frac{\partial \mathbf{h}^t}{\partial \mathbf{W}^t}$ ：第t步的隐状态对其对应权重的偏导。因为 $\mathbf{h}^t = f_t(\mathbf{h}^{t-1}, \mathbf{W}^t)$ ，所以这一项取决于具体的激活函数
  + $\frac{\partial \ell}{\partial \mathbf{W}^t}$ ：我们最终要求的梯度，用于更新权重
+ d-t次矩阵乘法
  + 从 $\mathbf{h}^d$ 传到 $\mathbf{h}^t$ ，中间经过了d-1，d-2，...，t+1，t，一共跨越了d-t个时间步
  + 因此，在计算梯度时，需要将这些时间步的雅可比矩阵**连续相乘d-t次**
+ 为什么这很重要：
这个“d−td−t 次矩阵乘法”正是 RNN 中著名的梯度消失（Vanishing Gradient）和梯度爆炸（Exploding Gradient）问题的根源：  
  + 如果这些雅可比矩阵的范数（特征值）普遍**小于 1**，那么随着 d−t 增大（即时间步跨度变长），连乘的结果会**指数级衰减**，导致梯度消失，模型无法学习到长距离的依赖关系（长时记忆）。
  + 如果范数普遍大于 1，连乘结果会**指数级增长**，导致梯度爆炸，训练不稳定。
**这个公式讲的是**：在深度序列模型中，误差信号是如何跨越多个时间步（或层）反向传播的，以及为什么长距离的连乘会导致梯度问题。
