## 权重衰退
最常见的处理过拟合的方法
### 控制模型的容量
+ 参数较小
**使用均方范数作为硬性限制**
+ 参数取值范围较小
  + w^2小于θ，每个w的值小于根号下θ
  + 通常不限制偏移b（限制不限制都差不多）
  + 小的θ意味着更强的正则项
    + 最强的情况是θ为0，只能选择一个偏移
    + w变多，w变小
<img width="877" height="477" alt="图片" src="https://github.com/user-attachments/assets/7be59da6-73ce-4c91-b1f4-ee9954249a21" />

**使用均方范数作为柔性限制**
+ 对每个θ，都可以找到λ使得之前的目标函数等价于下面
$\min \ell(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|^2$  
  + $\min \ell(\mathbf{w}, b)$ ：是原始损失函数
  + $\frac{\lambda}{2} \|\mathbf{w}\|^2$ ：这项是罚
    + w不会特别大
    + λ是超参数
      + λ趋于0，相当于硬性限制的θ趋于无穷：限制几乎不起作用
      + λ趋于无穷：相当于硬性限制的θ趋于0：限制很强，最优解也趋近于0（w*）
      + 想让模型不要太过复杂：λ增大
  + 可以通过拉格朗日乘子来证明
+ 超参数λ控制了正则项的重要程度
  + λ=0：无作用
  + λ→∞，w*→0

+ 绿色的线是硬性限制
  + 损失函数值所在loss
  + 中间的点是最优值所在
    + 从中间点向外走：l（loss）的值会变大，罚的值会变小（L2损失函数在原点附近向回拉的力度会小一些，远离原点位置的力度会大一些）
+ 黄色的线是柔性限制
+ 绿色和黄色线的交点是平衡点（也是最优解，是加入罚之后的最优解）
  + 向左下走：减少的项不足以弥补增加的项
  + 向右上走：罚的增加项比l的损失大
+ 罚的引入让最优解向原点走（绝对值变小，把最优解往左下角拉，模型的复杂度就降低了）

## 正则化
**正则化（Regularization）** 是机器学习和统计学中一种常用的技术，核心目的是防止模型过拟合，提高模型在新数据上的泛化能力。
简单来说，就是**在训练模型时，给模型的“复杂度”加上一个惩罚项**，让模型别把训练数据学得“太死”。
+ **不正则化**：你把练习册里每道题的答案都背下来，包括印刷错误。结果考试遇到新题就不会了。
+ **正则化**：你被要求“用最简单的方法解题”，不能死记硬背。这样你学到的是一般规律，遇到新题也能应对。
正则化就是在损失函数里加一句：**“不仅要预测准，还要模型简单”**。
### 常见的正则化
1. L1正则化（Lasso）
在损失函数中加入权重绝对值的和：
$L = L_0 + \lambda \sum |w_i|$  
+ 效果：会让一些权重直接变成 0
+ 特点：可以做**特征选择**，产生稀疏模型
2. L2正则化（Ridge/权重衰退）
在损失函数中加入权重平方和：
$L = L_0 + \lambda \sum w_i^2$  
+ 效果：让权重都变小，但通常不会变成 0
+ 特点：最常用，训练更稳定
3. Dropout
神经网络中随机“丢弃”一部分神经元，防止网络过度依赖某些节点。
4. 早停（Early Stopping）
在验证集误差开始上升时就停止训练，不让模型继续“背题”。
5. 数据增强
通过旋转、裁剪、加噪声等方式扩充训练数据，让模型见到更多变化。
### 关键参数：λ（正则化系数）
+ λ太大：惩罚过重，模型太简单->欠拟合
+ λ太小：惩罚不够，模型太复杂->过拟合
+ λ=0：相当于没有正则化  
所以 λ 需要调参找到平衡点。
>>正则化就是在让模型拟合数据的同时，限制它不要过于复杂，从而在“学得会”和“泛化好”之间找到平衡。
