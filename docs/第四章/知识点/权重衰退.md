#### 控制模型的容量
+ 参数较小
**使用均方范数作为硬性限制**
+ 参数取值范围较小
  + w^2小于θ，每个w的值小于根号下θ
  + 通常不限制偏移b（限制不限制都差不多）
  + 小的θ意味着更强的正则项
    + 最强的情况是θ为0，只能选择一个偏移
    + w变多，w变小
