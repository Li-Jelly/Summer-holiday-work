## 一、为什么权重初始化很重要

如果权重初始化不当，会直接导致：

| 问题 | 后果 |
|---|---|
| 梯度消失 | 深层网络中，反向传播的梯度逐层衰减，浅层几乎收不到有效梯度 |
| 梯度爆炸 | 梯度逐层放大，参数更新剧烈，训练发散 |
| 对称性问题 | 同一层神经元学到完全相同的特征，失去表达多样性 |
| 激活值分布偏移 | 每层输出均值/方差偏离合理范围，导致非线性饱和或信息丢失 |

**核心目标**：让每一层的输入和输出方差保持稳定，使信号在前向和反向传播中都不被过度放大或缩小。

---

## 二、四个核心问题详解

### 1. 梯度消失

#### 原理

Sigmoid 的导数：

$$\sigma'(x) = \sigma(x)(1-\sigma(x))$$

最大值是 **0.25**（当 $x=0$ 时）。也就是说，每经过一个 Sigmoid 层，梯度最多只剩 $\frac{1}{4}$。

#### 数值例子：5 层网络，每层 Sigmoid

反向传播时：

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial a_5} \cdot \sigma'_5 \cdot W_5 \cdot \sigma'_4 \cdot W_4 \cdots \sigma'_1$$

假设每层 $\sigma' \approx 0.25$，权重 $W \approx 1$：

| 层 | 梯度大致倍数 | 相对输出层 |
|---|---|---|
| 第 5 层（输出） | 1 | 100% |
| 第 4 层 | 0.25 | 25% |
| 第 3 层 | 0.0625 | 6.25% |
| 第 2 层 | 0.0156 | 1.56% |
| 第 1 层 | 0.0039 | **0.39%** |

到第 1 层时，梯度只剩原来的 **0.4%**，参数几乎不更新。

#### 为什么梯度小就学不到？

参数更新公式：

$$W \leftarrow W - \eta \cdot \frac{\partial L}{\partial W}$$

**权重更新量 = 学习率 × 梯度。**

- 梯度 = 0.0001，学习率 = 0.01 → 更新量 = 0.000001，权重几乎不动
- 梯度 = 1，学习率 = 0.01 → 更新量 = 0.01，权重明显更新

梯度小 → 更新量小 → 权重变化小 → 浅层特征不变 → **浅层"学不到"**。

> **类比**：传话游戏中，第 5 个人传给第 4 个人声音减半，第 4 传第 3 再减半……传到第 1 个人时已经微不可闻。第 1 个人不是不想改，而是收到的信号太弱，不知道该往哪个方向改。

#### 为什么靠近输出的层正常学习？

反向传播是从输出层往输入层逐层计算的：

$$\frac{\partial L}{\partial W_5} \rightarrow \frac{\partial L}{\partial W_4} \rightarrow \cdots \rightarrow \frac{\partial L}{\partial W_1}$$

- 输出层的梯度直接来自损失函数，**没有经过任何中间层的衰减**
- 越靠近输出，梯度在传播路径上经过的"衰减环节"越少
- 越靠近输入，经过的衰减环节越多

所以：**靠近输出 → 梯度大 → 更新正常 → 学得好；靠近输入 → 梯度被层层衰减 → 更新极小 → 学不到。**

#### 实际现象

- 训练时浅层权重几乎不变
- 损失下降很慢或停滞
- 靠近输出的层正常学习，靠近输入的层"冻住"

---

### 2. 梯度爆炸

#### 原理

假设一个 5 层网络，每层权重 $W = 3$，激活函数是线性的（或 ReLU 正半轴）：

前向传播：

$$a_1 = 3x,\quad a_2 = 9x,\quad a_3 = 27x,\quad a_4 = 81x,\quad a_5 = 243x$$

反向传播梯度：

$$\frac{\partial L}{\partial W_1} \propto 3^4 = 81$$

如果权重是 10：

$$10^4 = 10000$$

梯度呈指数级放大。参数更新量变成：

$$W \leftarrow W - \eta \cdot 10000$$

一步更新就可能把权重推到很离谱的值，损失变成 `NaN`。

#### 实际现象

- 损失突然变成 `NaN` 或 `inf`
- 参数值剧烈震荡
- 梯度范数极大
- 常见于 RNN 展开很多步、深层网络权重初始化过大

#### 缓解方法

- 梯度裁剪
- 合理初始化
- 归一化层

---

### 3. 对称性问题

#### 例子：所有权重初始化为 0

假设一个 2 输入、2 隐藏神经元的层：

$$W = \begin{bmatrix} 0 & 0 \\ 0 & 0 \end{bmatrix}, \quad b = \begin{bmatrix} 0 \\ 0 \end{bmatrix}$$

输入 $x = [x_1, x_2]$：

$$z_1 = 0 \cdot x_1 + 0 \cdot x_2 = 0$$

$$z_2 = 0 \cdot x_1 + 0 \cdot x_2 = 0$$

两个神经元输出完全相同。反向传播时，它们得到的梯度也完全相同：

$$\frac{\partial L}{\partial W_{1,:}} = \frac{\partial L}{\partial W_{2,:}}$$

更新后：

$$W_{1,:} = W_{2,:}$$

**永远保持相同**。这两个神经元本质上是一个神经元，网络容量浪费了一半。

#### 例子：所有隐藏层权重初始化为相同常数 0.5

$$z_1 = 0.5x_1 + 0.5x_2$$

$$z_2 = 0.5x_1 + 0.5x_2$$

输出一样，梯度一样，更新后仍然一样。

#### 结论

初始化必须**打破对称性**，让不同神经元有不同的初始权重。随机初始化（高斯、均匀、Xavier、He）都能做到这一点。

> **注意**：偏置 $b$ 初始化为 0 是可以的，因为只要权重不同，神经元就不同。但权重不能全相同。

---

### 4. 激活值分布偏移

#### 例子 1：初始化过小 → 激活值趋近于 0 → 信息丢失

假设每层权重 $W \sim \mathcal{N}(0, 0.01^2)$，输入 $x$ 标准差为 1，每层 1000 个输入。

每层输出方差：

$$\text{Var}(z) = n_{in} \cdot \text{Var}(W) \cdot \text{Var}(x) = 1000 \times 0.0001 \times 1 = 0.1$$

标准差 ≈ 0.316。逐层衰减：

| 层 | 标准差 |
|---|---|
| 1 | 0.316 |
| 2 | 0.1 |
| 3 | 0.0316 |
| 4 | 0.01 |
| 5 | 0.00316 |

到第 5 层，激活值几乎全是接近 0 的小数。如果后面接 Sigmoid，所有值都落在 0 附近，输出接近 0.5，**不同样本之间的差异被抹平**，网络无法区分输入。这就是**信息丢失**。

#### 例子 2：初始化过大 → 激活值饱和 → 梯度消失

假设权重 $W \sim \mathcal{N}(0, 1^2)$，输入维度 1000：

$$\text{Var}(z) = 1000 \times 1 \times 1 = 1000$$

标准差 ≈ 31.6。激活值大量落在 $[-100, 100]$ 这种范围。如果接 Sigmoid：

- $z = 50$ → $\sigma(50) \approx 1$
- $z = -50$ → $\sigma(-50) \approx 0$

Sigmoid 在 $|z| > 5$ 时导数已经接近 0：

$$\sigma'(50) \approx 0$$

反向传播时梯度被乘以这个接近 0 的导数，**梯度消失**。同时，Sigmoid 输出不是 0 就是 1，均值偏离 0，下一层输入分布偏移。

#### 例子 3：均值偏移导致方差膨胀

假设某层输出均值是 5，方差是 1。下一层权重 $W \sim \mathcal{N}(0, 1)$。

$$\text{Var}(z) = \mathbb{E}[W^2]\text{Var}(a) + \text{Var}(W)\mathbb{E}[a]^2 + \text{Var}(W)\text{Var}(a)$$

代入 $\mathbb{E}[W^2]=1$，$\text{Var}(a)=1$，$\mathbb{E}[a]=5$：

$$\text{Var}(z) = 1 \times 1 + 1 \times 25 + 1 \times 1 = 27$$

方差被放大了 **27 倍**。激活值分布迅速扩散，容易进入饱和区。

### 5. NaN 和 inf 是什么

#### inf：Infinity，无穷大

当数值超过计算机能表示的最大浮点数时，就变成 `inf`。

常见产生方式：

- **除以 0**：$\frac{1}{0} = \text{inf}$
- **数值爆炸**：float32 上限约 $3.4 \times 10^{38}$，超过就变 `inf`
- **指数溢出**：$e^{1000} = \text{inf}$

#### NaN：Not a Number，不是数字

NaN 表示"这个结果在数学上没有定义"。

常见产生方式：

| 运算 | 结果 |
|---|---|
| $0 / 0$ | NaN |
| $\text{inf} - \text{inf}$ | NaN |
| $\text{inf} / \text{inf}$ | NaN |
| $\sqrt{-1}$ | NaN |
| $\log(-1)$ | NaN |
| $0 \times \text{inf}$ | NaN |

#### 在训练中意味着什么

一旦损失变成 `NaN` 或 `inf`：

1. 梯度也会变成 `NaN` 或 `inf`
2. 权重更新：$W \leftarrow W - \eta \cdot \text{NaN} = \text{NaN}$
3. 所有权重变成 `NaN`
4. 之后所有前向传播输出都是 `NaN`
5. **训练彻底崩溃，无法恢复**

#### 典型崩溃过程

```text
第1步：loss = 2.3
第2步：loss = 15.7
第3步：loss = 892.1
第4步：loss = 1.2e15
第5步：loss = inf
第6步：loss = NaN   ← 训练死亡
```

#### 发现与处理

**发现：**

```python
if torch.isnan(loss) or torch.isinf(loss):
    print("训练崩溃了！")
    break

for name, param in model.named_parameters():
    if torch.isnan(param.grad).any():
        print(f"{name} 的梯度出现 NaN")
```

**处理：**

| 方法 | 说明 |
|---|---|
| 梯度裁剪 | `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)` |
| 减小学习率 | 更新步子太大容易爆炸 |
| 合理初始化 | He/Xavier，避免初始就爆炸 |
| 加 epsilon | `x = torch.log(p + 1e-8)` |
| 数值稳定实现 | 用 `log_softmax` 而不是先 softmax 再 log |
| 归一化层 | BN/LN 稳定激活值分布 |
| 混合精度 + loss scaling | float16 更容易溢出 |

## 三、常见权重初始化方法

### 1. 全零 / 常数初始化

- **全零**：所有神经元对称，梯度相同，等价于一个神经元。**不可用。**
- **常数（如 0.01）**：同样存在对称性问题，且方差随层数快速衰减。

### 2. 随机初始化

**高斯初始化**：$W \sim \mathcal{N}(0, \sigma^2)$

- $\sigma$ 太大 → 输出饱和、梯度消失
- $\sigma$ 太小 → 信号逐层衰减
- 需要手动调 $\sigma$，对深层网络不友好

**均匀初始化**：$W \sim U[-a, a]$

- 同样需要选择 $a$，缺乏理论指导

### 3. Xavier / Glorot 初始化

**适用场景**：Sigmoid、Tanh 等对称、线性区近似线性的激活函数。

**核心思想**：让前向传播和反向传播的方差保持一致。

前向方差条件：$\text{Var}(W) = \frac{1}{n_{in}}$

反向方差条件：$\text{Var}(W) = \frac{1}{n_{out}}$

两者折中：

$$\text{Var}(W) = \frac{2}{n_{in} + n_{out}}$$

对应：

- 正态：$W \sim \mathcal{N}\left(0, \frac{2}{n_{in}+n_{out}}\right)$
- 均匀：$W \sim U\left[-\sqrt{\frac{6}{n_{in}+n_{out}}}, \sqrt{\frac{6}{n_{in}+n_{out}}}\right]$

**局限**：推导假设激活函数在 0 附近近似线性。ReLU 在负半轴输出为 0，方差减半，Xavier 会偏小。

### 4. He / Kaiming 初始化

**适用场景**：ReLU 及其变体（Leaky ReLU、PReLU 等）。

ReLU 会把一半的输入置零，导致输出方差约为输入方差的一半。因此需要把方差放大一倍：

$$\text{Var}(W) = \frac{2}{n_{in}}$$

对应：

- 正态：$W \sim \mathcal{N}\left(0, \frac{2}{n_{in}}\right)$
- 均匀：$W \sim U\left[-\sqrt{\frac{6}{n_{in}}}, \sqrt{\frac{6}{n_{in}}}\right]$

对于 Leaky ReLU，修正为：

$$\text{Var}(W) = \frac{2}{(1+\alpha^2) n_{in}}$$

其中 $\alpha$ 是负半轴斜率。

### 5. LeCun 初始化

**适用场景**：SELU 激活函数。

$$\text{Var}(W) = \frac{1}{n_{in}}$$

配合 SELU 可以近似实现自归一化。

### 6. 正交初始化

- 权重矩阵初始化为正交矩阵，奇异值全为 1
- 优点：前向/反向传播时范数严格保持，缓解梯度消失/爆炸
- 常用于 RNN、深层网络、GAN 等

### 7. 预训练初始化 / 迁移学习

- 用在大规模数据上预训练的权重初始化，再微调
- 实践中非常有效，尤其在小数据集上

### 8. 数据依赖初始化

- 如 LSUV：先做正交初始化，再用一个 batch 数据逐层调整方差到 1
- 更精细，但计算成本高

## 四、激活函数的选择

### 1. Sigmoid

$$\sigma(x) = \frac{1}{1+e^{-x}}$$

- 输出范围 (0,1)，适合二分类输出层
- **问题**：
  - 饱和区梯度接近 0 → 梯度消失
  - 输出非零均值 → 后层输入偏移
  - 计算含指数，较慢
- **隐藏层基本不用**，输出层可用于二分类

### 2. Tanh

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

- 输出范围 (-1,1)，零均值
- 比 Sigmoid 好，但仍会饱和，深层网络仍有梯度消失
- 适合 RNN 中某些场景，隐藏层逐渐被 ReLU 系列取代

### 3. ReLU

$$\text{ReLU}(x) = \max(0, x)$$

- **优点**：
  - 正半轴梯度恒为 1，缓解梯度消失
  - 计算极快
  - 稀疏激活
- **缺点**：
  - 负半轴梯度为 0 → 神经元死亡
  - 输出非零均值
- **现代深层网络默认起点**，配合 He 初始化

### 4. Leaky ReLU / PReLU

$$\text{LeakyReLU}(x) = \max(\alpha x, x), \quad \alpha \text{ 小常数}$$

- 解决 ReLU 神经元死亡问题
- PReLU 把 $\alpha$ 设为可学习参数
- 效果不一定总优于 ReLU，但常作为备选

### 5. ELU / SELU

$$\text{ELU}(x) = \begin{cases} x, & x>0 \\ \alpha(e^x-1), & x\le 0 \end{cases}$$

- 负半轴平滑，输出接近零均值
- SELU 配合 LeCun 初始化可自归一化
- 计算含指数，稍慢

### 6. GELU

$$\text{GELU}(x) = x \cdot \Phi(x)$$

- 用高斯累积分布函数平滑门控
- Transformer 系列（BERT、GPT）常用
- 效果通常优于 ReLU，计算稍复杂

### 7. Swish / SiLU

$$\text{Swish}(x) = x \cdot \sigma(\beta x)$$

- Google 提出，平滑、非单调
- SiLU 是 $\beta=1$ 的特例
- 在深层网络中表现良好

### 8. Softmax

- 用于多分类输出层，把 logits 转为概率分布
- 不用于隐藏层

### 9. Maxout

- 取多个线性函数的最大值
- 表达能力强，但参数和计算量成倍增加
- 现在较少使用

## 五、初始化与激活函数的匹配

| 激活函数 | 推荐初始化 | 原因 |
|---|---|---|
| Sigmoid | Xavier/Glorot | 0 附近近似线性，对称 |
| Tanh | Xavier/Glorot | 同上，零均值 |
| ReLU | He/Kaiming | 负半轴置零，方差减半 |
| Leaky ReLU | He（带 α 修正） | 负半轴有输出 |
| SELU | LeCun | 自归一化要求 |
| GELU/Swish | He 或 Xavier | 近似 ReLU，He 更稳 |
| 线性 | Xavier 或小方差 | 无非线性压缩 |

**匹配原则**：

1. 先看激活函数在 0 附近的线性程度和负半轴行为
2. 若负半轴输出为 0（ReLU），用 **He**
3. 若负半轴有输出且近似线性（Tanh、Sigmoid），用 **Xavier**
4. 若激活函数有自归一化设计（SELU），用对应初始化
5. 不确定时，**He 初始化 + ReLU/GELU** 是稳妥默认

---

## 六、四个问题的连锁关系

它们不是独立的，常常一起出现：

```text
初始化过大
  → 激活值方差膨胀
  → 进入饱和区
  → 梯度消失（饱和区导数≈0）
  → 浅层学不到

初始化过小
  → 激活值逐层衰减
  → 信息丢失
  → 梯度也逐层衰减
  → 浅层学不到

初始化全相同
  → 对称性
  → 神经元冗余
  → 表达能力下降

权重过大 + 无归一化
  → 前向值爆炸
  → 反向梯度爆炸
  → 数值超过浮点上限
  → inf → NaN
  → 训练崩溃
```

**合理初始化 + 合适激活函数 + 归一化层**，就是在同时解决这四个问题：

- **随机** → 打破对称
- **方差控制在 $1/n_{in}$ 或 $2/n_{in}$** → 防止消失/爆炸
- **激活函数选择匹配** → 保持分布稳定
- **BN/LN** → 强制拉回合理分布

## 七、PyTorch 实验

```python
import torch
import torch.nn as nn

def test_init(init_fn, activation, depth=10, dim=512):
    layers = []
    for _ in range(depth):
        linear = nn.Linear(dim, dim)
        init_fn(linear.weight)
        nn.init.zeros_(linear.bias)
        layers.append(linear)
        layers.append(activation())
    model = nn.Sequential(*layers)
    
    x = torch.randn(64, dim)
    with torch.no_grad():
        for i, layer in enumerate(model):
            x = layer(x)
            if isinstance(layer, nn.Linear):
                print(f"层{i//2}: 均值={x.mean():.4f}, 标准差={x.std():.4f}")
    print("---")

# 小初始化 + Sigmoid
test_init(lambda w: nn.init.normal_(w, 0, 0.01), nn.Sigmoid)

# 大初始化 + Sigmoid
test_init(lambda w: nn.init.normal_(w, 0, 1.0), nn.Sigmoid)

# He 初始化 + ReLU
test_init(lambda w: nn.init.kaiming_normal_(w, nonlinearity='relu'), nn.ReLU)
```

**预期结果**：

- 小初始化：标准差逐层衰减到接近 0
- 大初始化 + Sigmoid：标准差先爆炸，然后饱和
- He + ReLU：标准差在各层保持相对稳定

## 八、实践建议

| 场景 | 推荐组合 |
|---|---|
| 默认 | ReLU/GELU + He 初始化 + BN/LN |
| 深层网络 | 残差连接 + He 初始化 |
| RNN | 正交初始化 + Tanh/LSTM，或 LayerNorm |
| Transformer | Xavier/He + LayerNorm + GELU/SwiGLU |
| 小数据集 | 预训练权重微调 |

**监控手段**：

- 观察每层激活值的均值和方差
- 观察梯度范数逐层变化
- 若某层激活大量为 0，检查是否神经元死亡或初始化过小
- 若损失震荡发散，检查是否初始化过大或学习率过高

---

## 九、总结

核心公式始终是：

$$\Delta W = \eta \cdot \frac{\partial L}{\partial W}$$

- 梯度太小 → 学不到
- 梯度太大 → 爆炸成 inf/NaN

> **权重初始化的目标是让每层方差稳定，激活函数的选择决定了方差如何变化；两者必须匹配——ReLU 配 He，Sigmoid/Tanh 配 Xavier，SELU 配 LeCun，不确定时用 He + ReLU/GELU + 归一化层。**
