## 模型选择
### 前例——预测贷款归还
#### 信号发现
+ 所有的5个人面试的时候都穿了衬衫
+ 模型也发现了这个**强信号**
#### 关注误差
##### 训练误差
模型在训练数据集上的误差（模拟考成绩）
##### 泛化误差（关注）
模型在新数据上的误差（高考成绩）
#### 数据集（计算误差）
##### 训练数据集
训练参数的数据集
+ **用途**：训练参数
##### 验证数据集
评估模型好坏的数据集
+ **用途**：验证数据集的好坏 或 调整超参数（也有可能虚高）
##### 测试数据集
**只能用一次的数据集**
+ **用途**：看模型的真正泛化能力
**注意**：验证数据集和测试数据集**不能放在一起**
#### K-则交叉验证（非 大数据集上）
+ 没有足够多的数据（常态）时使用
+ 算法：
  + 先随机打乱数据集
  + 将训练数据分隔成K块
  + For i=1,...,K
    + 使第i块作为验证数据集，其余的作为训练数据集
  + 报告K个验证集**误差的平均**
+ 常用：K=5或10
  + 极端：使K=N，即每个数据都作为验证数据集，验证数据集每次只有一个数据，可以最大化利用数据集，但是比较贵（要跑N次）
