## 过拟合和欠拟合
### 是什么
<img width="802" height="448" alt="图片" src="https://github.com/user-attachments/assets/3844bdd7-b2d4-4283-850f-d7864d40867d" />

+ **正常**：简单数据低模型容量，复杂数据高模型容量
+ **欠拟合**：复杂数据低模型容量（无法拟合或者精度不好）
+ **过拟合**：简单数据高模型容量（直接记住每个样本的模样，泛化能力不好，噪声也记住了）
**选择顺序**：根据数据集的简单复杂来选择模型容量
#### 模型容量
模型容量即模型的复杂度，复杂的模型可以学习复杂的函数
+ 拟合各种函数的能力
+ 低容量的模型难以拟合训练数据
+ 高容量的模型可以记住所有的训练数据

**影响**：

+ 模型容量高：
  + 训练误差：高
  + 泛化误差：高
+ 模型容量低：
  + 训练误差：低
  + 泛化误差：有所降低，但比训练误差高（模型记住了数据点，有大量的噪音，**关注了过多无关细节**）再往后可能上升
+ 最优点：泛化误差从下降开始变为上升的点
+ Gap：训练误差和泛化误差直接的Gap用来估计模型的过拟合和欠拟合的程度（最小的Gap处即为最优点）
+ 有时候为了降泛化误差，可能会让模型过拟合
#### 估计模型容量

  + 参数的个数
  + 参数值的选择范围（在大范围中选择参数，模型的复杂度会比较高）

  + d个w，1个b

#### VC维
+ 统计学习的核心思想
+ 对于一个分类模型，VC等于一个最大的数据集的大小，不管如何给定标号，都存在一个模型来对它**进行完美分类**
+ 简单讲：对于一个分类模型来讲，VC维就是**能够用一个模型进行完美分类的最大数据集大小**（和标号无关）
  + 二维输入的感知机（输入是2，输出是3），VC维=3（能够进行完美分类的数据集最多只有三个点，4个点如果是XOR问题就无法进行）
  + 支持N维输入的感知机的VC维是N+1
  + 一些多层感知机的VC维O(N log2 N)，比线性多一个log2 N
+ 优点：提供一个模型好的理论依据
  + 它可以衡量训练误差和泛化误差之间的间隔
+ 缺点：深度学习中很少用
  + 衡量不是很准确
  + 计算深度学习模型的VC维很困难（没有激活函数或者激活函数简单，可以计算出来VC维）
##### 为什么N维输入的感知机，其VC维是N+1维
因为在N维空间中，一个超平面**最多可以“打撒”(shatter)N+1个处于一般位置的点，但无法打撒N+2个点**
**VC 维的定义**：模型能“打散”的最大点集大小。所谓打散，就是对于这组点的所有可能的 2^m 种二分类标签组合，都能找到一个感知机假设与之完全一致。
**为什么是N+1**：
+ 在 N 维空间中，一个超平面由 N+1 个参数决定（N 个权重 + 1 个偏置）。
+ 从几何上看，N+1 个处于**一般位置**（即任意 N 个点不共面、不退化）的点，总能被一个超平面以任意方式分开。
+ 但 N+2 个点就不行了：无论怎么摆放，总会存在某些标签组合无法被超平面实现。
**经典例子**：
+ N=1（一维直线）：感知机是一个点，VC 维 = 2。一条直线上的 2 个点可以被任意分类（正负、负正、全正、全负），但 3 个点不行。
+ N=2（二维平面）：感知机是一条直线，VC 维 = 3。平面上 3 个不共线的点可以被任意分类，但 4 个点不行（经典的 XOR 问题）。
+ N=3（三维空间）：感知机是一个平面，VC 维 = 4。
##### 数学证明思路
1. 证明 VC 维 ≥ N+1：存在 N+1 个点能被打散
取 N+1 个点：原点 00 和 N 个坐标轴上的单位向量 e1,e2,…,eNe1​,e2​,…,eN​。
即：  
$\mathbf{x}_0 = (0, 0, \dots, 0), \quad \mathbf{x}_i = (0, \dots, 1, \dots, 0)$（第 i 个分量为 1）  
对于任意给定的标签 y0,y1,…,yN∈{−1,+1}y0​,y1​,…,yN​∈{−1,+1}，我们需要找到 w,bw,b 使得：
$\text{sign}(\mathbf{w}^T \mathbf{x}_i + b) = y_i$
+ 对于原点：sign(b)=y0sign(b)=y0​，所以 bb 的符号由 y0y0​ 决定。
+ 对于 xixi​：sign(wi+b)=yisign(wi​+b)=yi​。
由于 bb 已经确定（比如 b=y0b=y0​ 或任意同号值），我们可以独立地选择每个 wiwi​ 来满足对应的 yiyi​。例如：
+ 若 yi=y0yi​=y0​，取 wiwi​ 足够大且与 y0y0​ 同号；
+ 若 yi=−y0yi​=−y0​，取 wiwi​ 足够大且与 y0y0​ 反号。  
这样总能找到合适的 ww。因此这 N+1 个点可以被打散，所以 VC 维 ≥ N+1。
2. 证明 VC 维 ≤ N+1：任意 N+2 个点都不能被打散
需要用到Radon 定理或线性相关的论证。
**关键引理**:在 N 维空间中，任意 N+2 个点都是仿射相关的。即存在不全为零的系数 α0,α1,…,αN+1α0​,α1​,…,αN+1​，使得：  
$\sum_{i=0}^{N+1} \alpha_i \mathbf{x}_i = 0, \quad \sum_{i=0}^{N+1} \alpha_i = 0$  
并且这些 αiαi​ 中既有正数也有负数（因为和为零且不全为零）。
现在假设这 N+2 个点能被感知机打散。那么对于任意标签分配，都存在 w,bw,b 使得：
$y_i(\mathbf{w}^T \mathbf{x}_i + b) > 0 \quad \forall i$
特别地，我们考虑一种特殊的标签分配：令 yi=sign(αi)yi​=sign(αi​)（即正系数对应 +1，负系数对应 -1，零系数可任取但这里可忽略）。由于假设能打散，存在 w,bw,b 满足：
$\text{sign}(\alpha_i)(\mathbf{w}^T \mathbf{x}_i + b) > 0$
两边乘以 ∣αi∣∣αi​∣ 并求和：
$\sum_i |\alpha_i| \cdot \text{sign}(\alpha_i)(\mathbf{w}^T \mathbf{x}_i + b) = \sum_i \alpha_i(\mathbf{w}^T \mathbf{x}_i + b) > 0$
但左边等于：
$\mathbf{w}^T \sum_i \alpha_i \mathbf{x}_i + b \sum_i \alpha_i = \mathbf{w}^T \cdot 0 + b \cdot 0 = 0$
这就产生了矛盾：0 > 0 不成立。因此，不存在这样的 w,bw,b，即这 N+2 个点不能被这种标签分配所实现，所以不能被完全打散。
因此 VC 维 ≤ N+1。
结合两方面，VC 维 = N+1。  
#### 数据复杂度
多个重要因素
+ 样本个数（nn.Flatten()）
+ 每个样本的元素个数（照片的像素）
+ 时间、空间结构（视频）
+ 多样性（类别）

## 总结
+ 模型容量需要匹配数据复杂度，否则可能欠拟合和过拟合
+ 统计机器学习提供数学工具来衡量模型复杂度
+ 实际中一般靠观察训练误差和验证误差之间的差值
