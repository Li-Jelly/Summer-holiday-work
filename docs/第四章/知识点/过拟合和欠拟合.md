## 过拟合和欠拟合
### 是什么
<img width="802" height="448" alt="图片" src="https://github.com/user-attachments/assets/3844bdd7-b2d4-4283-850f-d7864d40867d" />

+ **正常**：简单数据低模型容量，复杂数据高模型容量
+ **欠拟合**：复杂数据低模型容量（无法拟合或者精度不好）
+ **过拟合**：简单数据高模型容量（直接记住每个样本的模样，泛化能力不好，噪声也记住了）
**选择顺序**：根据数据集的简单复杂来选择模型容量
#### 模型容量
模型容量即模型的复杂度，复杂的模型可以学习复杂的函数
+ 拟合各种函数的能力
+ 低容量的模型难以拟合训练数据
+ 高容量的模型可以记住所有的训练数据
<img width="887" height="497" alt="图片" src="https://github.com/user-attachments/assets/94c0220f-a073-4701-8825-c42a9517f753" />

**影响**：
<img width="887" height="484" alt="图片" src="https://github.com/user-attachments/assets/9d2be483-2f36-4a2c-984b-a3714b99f2da" />

+ 模型容量高：
  + 训练误差：高
  + 泛化误差：高
+ 模型容量低：
  + 训练误差：低
  + 泛化误差：有所降低，但比训练误差高（模型记住了数据点，有大量的噪音，**关注了过多无关细节**）再往后可能上升
+ 最优点：泛化误差从下降开始变为上升的点
+ Gap：训练误差和泛化误差直接的Gap用来估计模型的过拟合和欠拟合的程度（最小的Gap处即为最优点）
+ 有时候为了降泛化误差，可能会让模型过拟合
#### 估计模型容量
+ 难以在不同的种类算法之间比较
  + 例如树模型和神经网络
+ 给定一个模型种类，将有两个主要因素（控制模型得到复杂度）
  + 参数的个数
  + 参数值的选择范围（在大范围中选择参数，模型的复杂度会比较高）
单层：
  + d个w，1个b
多隐藏层：
  + 每层d和w，1个b
  + m个隐藏层
  + 最后类别数为k
