## 问题
### 什么是线性回归
#### 定义
**线性回归**是机器学习中最典型的模型之一，它通过构建线性方程来拟合数据的内在分布规律，从而实现对**连续数值**的预测（分类问题研究的是**离散数据**，比如类型有几种）
#### “回归”的由来
##### 高尔顿的“回归均值”
“回归”一词源于统计学家弗朗西斯·高尔顿的经典研究。他观察到，身高极高或极矮的父母，其子女的身高往往会向群体平均值靠拢，这一现象被称为“回归均值”。
##### 机器学习领域
“回归”的概念被进一步引申：旨在通过数据建模变量间的映射关系（即**输入与输出之间的关系**），进而实现对连续数值的预测
#### 线性
“线性”指输入与输出之间的关系是一个**线性方程**
#### 线性！=直线
在数学上，线性描述的是**输入与输出之间按比例变化、可叠加的关系**。一个映射f满足：
+ **齐次性**: $f(ax) = a \cdot f(x)$

+ **可加性**: $f(x + y) = f(x) + f(y)$

几何解释：在一维空间中，线性关系表现为一条直线；在高位空间中，表现为平面或超平面
#### 模型公式
最简单的线性回归模型只有一个特性（如房屋面积），预测公式为：

$\hat{y} = wx + b$
+ $\hat{y}$ ：模型的预测值（如预测房价）
+ $x$ ：输入特征（如房屋面积）
+ $w$ ：权重（weight，斜率）——面积每增加1㎡，房价变化多少
+ $b$ ：偏置（bias，截距）——当面积为0时的理论基准值
这里的 $w$ 和 $b$ 就是模型需要学习的参数，训练模型本质上就是搜索一组最合适的 $w$ 和 $b$ 
#### 损失函数：衡量模型准不准
模型要找到好的参数，首先要回答问题：当前这组参数到底好不好  
我们需要一种方法来度量预测值与真实值之间的偏差————**损失函数**
### 均方误差（MSE：L2）
1. 对每个样本，计算预测值-真实值（即误差）
2. 将误差取平方（消除正负号；在求导优化时，让大误差的梯度权重远大于小误差，从而迫使模型优先修正哪些偏差极大的样本）
3. 对所有样本求平均

$MSE = \frac{1}{n} \sum (\hat{y} - y)^2$

>>预测值离真实值越远，损失越大。模型训练的目标，就是让损失函数的值尽可能小。
#### 为什么使用MSE
+ **消除正负号影响**：让误差绝对值化，防止求和之后正负误差互相抵消
+ **放大误差便于优化**：例如3和0.4，平方后变为9和0.16（不准的更不准，准的更准）——惩罚项

### 梯度下降：寻找最优解
知道当前模型有多不准之后，自动调整 $w$ 和 $b$ 
最通用的算法是**梯度下降**：沿着损失函数下降最快的方向，逐步调整参数，直至找到最优解
>>形象比喻：蒙眼下山
>>+ 感知坡度（计算梯度）：盲人用脚探知当前所处的坡度方向，确定哪里是下坡
>>+ 迈出一小步（更新参数）：顺着最陡峭的下坡方向（负梯度方向），迈出一步
>>+ 循环往复（迭代优化）：在新位置继续感知坡度，继续向下走
>>+ 到达谷底（模型收敛）：当走到再也没有下坡路的地方，即认为到达了最低点
如果有多个特征，就求多个特征的偏导数
#### 梯度函数把损失函数变小
+ 在线性回归中，可以用**最小二乘法**算出最小损失函数
+ 在**数据量大、特征非常多**的情况下，还是用梯度下降
### 模型训练的核心
把下山的比喻和机器学习概念对应起来：
+ 山的当前高度=损失函数的值（Loss）走到山底就是想办法**让损失函数接近0**
+ 下坡的方向=梯度（Gradient,即导数）
+ 每一步迈多大=学习率（Learning Rate）
>训练流程
>输入数据--->计算预测--->计算损失--->计算梯度--->更新参数
>每完成一轮循环参数就更接近一点，经过多轮迭代模型逐渐收敛到最优解
### 多特征线性回归
房价的影响因素还包括：楼层、距地铁的距离、房龄等
#### 线性回归拓展特征
现在有d个特征，模型自然地扩展为：
$\hat{y} = w_1x_1 + w_2x_2 + w_3x_3 + \cdots + w_dx_d + b$

$\hat{y} = w_1 \cdot x_{\text{面积}} + w_2 \cdot x_{\text{楼层}} + w_3 \cdot x_{\text{距地铁}} + w_4 \cdot x_{\text{房龄}} + b$

- \( w_1 \)（面积）：+ 正，面积越大，房价越高  
- \( w_2 \)（楼层）：+ 正，中高楼层通常更贵  
- \( w_3 \)（距地铁）：- 负，离地铁越远，房价越低  
- \( w_4 \)（房龄）：- 负，房子越老，房价越低

### 代码实现
使用python的scikit-learn库可以非常方便地完成多特征线性回归的训练和预测：
```
import numpy as np
from sklearn.linear_model import linearRegression

#1.准备阶段：4个特征（面积、楼层、距地铁、房龄）
X=np.array([
  [50, 3, 0.5, 5],
  [70, 15,1.2,10],
  [90, 8, 0.3, 2],
  [110,20,2.0,15],
  [130,12,0.8, 8],
])
y=np.array([180,210,320,280,380])  #总价（万元）

#2.训练模型
model=LinearRegression()           #模型的初始化
model.fit(X,y)

#3.查看学到的权重
feature_names=['面积','楼层','距地铁','房龄']
print("各特征权重：")
for name,w in zip(feature_names,model.coef_):
  print(f"{name}:{w+2f}")
print(f"偏置 b:{model.intercept_:2f}")

#4.预测新数据：100㎡、10楼、距地铁0.6km、房龄5年
new_house=np.array([100,10,0.6,5])
pred=model.predict(new_house)
print(f"\n预测房价：{pred[0]:.1f} 万元")
```
### 用向量简化表达
当特征很多时，把公式全部展开写会非常冗长，借助向量的记号，可以将其写得更简洁：
$\hat{y} = w^T x + b$
不管是1个特征还是100个特征，模型的本质结构完全一样————都是特征的**加权求和和再加偏置**

### 多项式回归：当直线不够用时
现实中的数据并不总是沿着一条直线分布，比如当房价随面积增长先慢后快时，直线就无法很好地拟合了。这时可以引入多项式回归：

$\hat{y} = w_1x + w_2x^2 + \cdots + w_dx^d + b$
+ 当d=1时，就是普通的线性回归
+ 当d=2时，拟合出的是一条抛物线；阶数越高，曲线就越灵活
>>尽管公式中出现了 $x^2$ $x^3$ 等非线性项，但**模型对参数仍然是线性的**（\(\hat{y}\) 是 \(w_1, w_2, \dots, w_d, b\) 的线性组合），因此**多项式回归本质上仍属于广义线性模型的范畴**，可以用与线性回归相同的方法来求解

### 逻辑回归与深度学习
线性回归虽然简单，却是更复杂模型的起点，它可以自然地延伸出两个重要方向：
#### 逻辑回归（线性回归+激活函数——预测离散值）
用于解决分类问题（如判断垃圾邮件），输出概率：
$P(y = 1 \mid x) = \sigma(wx + b)$

$= \frac{1}{1 + e^{-(wx+b)}}$

值总在[0,1],小于0.5=0，大于0.5=1
#### 深度学习（多层逻辑回归的叠加）
将许多个“先行变换+激活函数”逐层堆叠构成神经网络：
**输入** $\rightarrow$ **线性+激活** $\rightarrow$ **隐藏层1** $\rightarrow$ **线性+激活** $\rightarrow$ **隐藏层2** $\rightarrow$ $\cdots$ $\rightarrow$ **输出**  
**核心思想**：模型**自动学习**并提取抽象特征
>>深度学习是线性回归思想的逐步演化与层层叠加
### 机器学习核心思想
+ **用数据寻找规律**
+ **用模型表达规律**
+ **用损失函数衡量误差**
+ **用梯度下降优化参数**（最小化损失函数）
+ **不断训练让模型变得更准确**
### 最大似然估计（MLE）
#### 定义
在已知结果（数据）的情况下，反推最有可能导致这个结果的原因（模型参数）是什么
#### 举个栗子（抛硬币）
+ **场景**：有一枚硬币，不知道是否均匀（正面概率p是多少）。抛了10次，结果7次正面，三次反面
+ **最大似然估计**：要找出一个p值，使得“抛10次出现7正3反”这个**事件发生的概率最大**
计算一下：
+ 假设p=0.5（均匀），出现7正3反的概率= $C_{10}^7 \times 0.5^7 \times 0.5^3 \approx 0.117$
+ 假设p=0.7（偏正面），出现7正3反的概率= $C_{10}^7 \times 0.7^7 \times 0.3^3 \approx 0.267$
因为0.267>0.117，所以**最大似然估计会说**：p-0.7比p=0.5 更像**真实情况**，这个**让观测结果概率最大的p值**，就是MLE的解
#### 在深度学习中的对应
+ 模型参数（权重 $w$ ）就是那个“硬币概率p”
+ 训练数据（X,Y）就是“抛硬币的结果”
+ MLE的目标：调整 $w$ ，使得“看到当前这堆训练数据”这件发生的概率最大化
+ 取负对数（为了把连乘变连加）后，**MLE就等于“最小化损失函数”**
>>核心结论：深度学习的“损失函数”不是凭空发明，**每一个损失函数背后，都隐含着一个概率分布假设**。选MSE就代表做MLE，且假设数据服从高斯分布
### 深度学习背后的数学分布
#### 为什么是高斯分布
+ **中心极限定理（数学必然）**：现实中的噪声往往是**无数个微小独立因素叠加**的结果（传感器热噪声、读数时的微小振动、环境光线变化）。这些因素叠加起来，根据中心极限定理，**无论单个因素是什么分布，它们的总和趋近于高斯分布**。所以高斯是“最自然”的默认假设。
+ **数学计算最友好（工程便利）**：高斯的指数形式 $e^{-x^2}$ 求导后恰好是线性（MSE梯度，-2e），使得梯度下降极其顺畅，没有断点
+ **最大熵原理（信息论）**：在只知道“均值和方差”两个统计量的情况下，**高斯分布是熵最大（最混乱、最保守、对未知最公平）的分布**，选它意味着“不瞎猜数据的额外结构”
#### 为什么是拉普拉斯分布
当数据中存在“极端异常值”时
+ 拉普拉斯分布的概率密度函数 $e^{-|x|}$ 在0处有个**尖峰**，在尾巴处比高斯**更厚**（出现极大值的概率更高）
+ **对应场景**：金融交易中的“黑天鹅”事件、图像中的离群像素、语音信号中的突发爆音，这些场景下，高斯假设太“乐观”（认为大误差几乎不可能发生），所以换成拉普拉斯（允许大误差有一定概率出现）
#### 其他的分布类型
|噪声分布类型|概率密度形状|对应损失函数|典型应用场景|
|:----:|:---:|:---:|:---:|
|高斯分布|钟形曲线（轻尾）|MSE(L2)|图像超分、物理模拟、传统回归|
|拉普拉斯分布|尖峰+重尾|MAE(L1)|金融风险、异常检测、有离群点的回归|
|Huber分布（混合）|中间高斯+两边拉普拉斯|Huber Loss|工业界通用鲁棒回归（自动驾驶测距）|
|Logistic分布|类似高斯但尾巴稍重|交叉熵损失（分类）|二分类/多分类（输出概率）|
|泊松分布（离散）|右偏分布（长尾巴）|泊松负对数似然|计数预测（如一天内到店顾客数）|
|Beta分布|[0,1]区间上的任意形状|Beta负对数似然|点击率预测（CTR）中的转化率|
|学生t分布|极重尾（比拉普拉斯更重）|t-分布损失|存在大量离谱离群点的鲁棒回归|
|高斯混合分布|双峰/多峰|GMM损失|多模态数据（如不同光照下的同一物体）|
+ **高斯分布**： 默认客人身材标准（误差集中在小范围）→ 你按标准尺码（MSE）裁衣，效率最高
+ **拉普拉斯分布**： 默认客人可能存在“极端体型”（大误差可能出现）→ 你用松紧带（MAE）裁衣，防止客人穿不上
+ **学生t分布**：默认客人可能是个“极端变形怪”→ 你用超弹力面料（t-loss），怎么离谱都能兜住
+ **泊松分布**：默认要预测的是“计数”（非负整数，且方差随均值增大）→ 你用专门的泊松回归损失
#### 如何用“残差直方图”来判断该选哪种损失函数
残差=真实值-预测值
**核心逻辑**：残差的分布，就是“模型和数据之间，还剩什么样的误差”，损失函数的选择本质上就是**选择一种分布去拟合这个残差**
|直方图形状|说明什么|推荐损失|
|:---:|:---:|:---:|
|中间高、两边快速下降（钟形）|残差集中在0附近，大误差极少|MSE（高斯假设成立）|
|中间极高极尖、两边尾巴拖得很长（尖峰重尾）|大部分误差极小，但偶尔出现巨大偏差（有离群点）|Huber 或 MAE|
|中间很平坦，分布臃肿（平顶）|误差在各个区间分布均匀，没有明显集中趋势|警惕！数据质量差或特征缺失|
**看尾巴厚度：**
+ **轻尾**（残差大于三倍标准差的数量极少）：MSE是首选，收敛快
+ **中尾**（存在一些明显偏离的离群点）：果断用Huber Loss，让大误差段的梯度从线性（MSE的2倍）降为常数（MAE的1倍）
+ **重尾**尾巴拖得非常长，甚至出现比均值大10倍的残差）：直接用MAE或更鲁棒的Log-Cosh
**看对称性：**
+ **对称**：正常，上述选择有效。
+ **严重右偏或左偏**（残差分布歪向一边）：说明模型存在系统性偏差（比如房价预测中，高价房总是被低估）。此时换损失函数没用了，需要先对标签做对数变换（log-transform），把偏态分布拉成对称，再画图重选。

### 分类和回归的根本分歧
#### 函数选择
回归用MSE，分类用交叉熵
#### 回归任务（MSE）--输出是实数，噪声是加性的
+ **输出空间**： $y \in (-\infty, +\infty)$ 或某个连续区间
+ **数据生成假设**： $y = f(x) + \epsilon$ 其中 $ \epsilon$ 是**加性噪声**（独立于输入）
+ **为什么用高斯**：如果你认为这个加性噪声来自无数微小因素叠加（中心极限定理），那么 $\epsilon \sim \mathcal{N}(0, \sigma^2)$
+ **MLE推导出的损失**： $-\log p(y|x) = \text{const} + \frac{(y - f(x))^2}{2\sigma^2}$
#### 分类任务（交叉熵）--输出是概率，噪声是“随机选择”
+ **输出空间**： $y \in \{0, 1\}$ （二分类）或One-hot向量（多分类）
+ **数据生成假设**：模型输出的是概率 $p = P(y = 1 | x)$ ，而真实标签y是根据这个概率**做了一次随机伯努利试验**得到的
+ **这里的“噪声”不是加性的**，而是**采样噪声**——即使模型完美预测了p=0.9，仍有10%的概率看到标签y=0，这种噪声的分布是**伯努利分布（二分类）或分类分布（多分类）**

### 均方误差（MSE：L2）
1. 对每个样本，计算预测值-真实值（即误差）
2. 将误差取平方（消除正负号；在求导优化时，让大误差的梯度权重远大于小误差，从而迫使模型优先修正哪些偏差极大的样本）
3. 对所有样本求平均
#### 均方误差平方的核心原因
深度学习的优化靠**梯度下降**，我们看损失对输出 $\hat{y}$ 的导数（梯度与误差大小成正比）：

$\frac{\partial e^2}{\partial \hat{y}} = -2e$

当误差 $e=3$ 时，MSE的梯度是 $−6$；当误差 $e=0.1$ 时，梯度是 $−0.2$  
这意味着**大误差样本会获得的“更新力度”是小样本误差的30倍**，在参数更新时，模型会分配不成比例的注意力去修正大误差点
#### 更深层的假设（高斯噪声）
这是最容易被忽略的点：**MSE是假设目标服从高斯分布（正态分布）时的最大似然估计（MLE）结果**，而不是认为设计的“放大”技巧。如果用绝对误差，其实隐含的假设是拉普拉斯分布（噪声更稀疏、有重尾）
#### 现在不常用MSE的原因
在深度学习，尤其是**分类问题**中，MSE表现不好（恰恰因为“平方放大较大误差”），被交叉熵取代：
+ **对离群点过于敏感**：如果有一个样本噪声极大（标签标错），MSE会给它巨大的梯度，导致模型参数被带偏，去拟和这个错误点
+ **梯度饱和问题**：如果用Sigmiod/Tanh作为输出层，当误差很大时，输出已经处于饱和区（导数接近0），此时MSE的梯度虽然是 $-2e$ ，但乘以激活函数的导数≈0，结果梯度还是接近0，导致**大误差时反而更新不懂**（这就是“梯度消失”），**交叉熵没有这个问题**
#### 总结
取平方是为了**让梯度与误差线性相关，实现“大错特错，大理修正”的注意力分配机制，同时它源自高斯噪声的统计假设**
