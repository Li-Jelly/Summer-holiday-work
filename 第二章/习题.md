## 问题
### torch 和 tensor的区别
正确写法是```torch.tensor()``` ```torch.zeros()``` ```torch.ones()```
+ **torch**：模块名
+ **tensor**：函数名
+ **zeors**：函数名
+ **ones**：函数名
+ **命名规则**：torch.函数名()
+ ```tensor```不是一个独立的对象，只是```torch```模块里的一个函数
+ 所有PyTorch的函数都在```torch```这个命名空间下
+ 除非提前执行了```from torch import tensor```,然后才可以写```tensor(...)```，但仍不能写```tensor.zeros(...)```
### rand 和 randn的区别
+ **rand**:均匀分布，取值在[0,1)之间
+ **randn**:标准正态分布（均值为0，方差为1），取值理论上在（-∞，+∞）之间

| 特性          | `torch.rand()`             | `torch.randn()`               |
|:---------------:|:-------------------------:|:-------------------------------:|
| 分布名称      | 均匀分布                   | 标准正态分布                  |
| 取值范围      | \([0, 1)\)                 | 理论上 \((-\infty, +\infty)\)，实际约 \([-3, 3]\) |
| 概率密度      | 每个值概率相等             | 中间值概率高，两端概率低      |
| 均值          | 0.5                        | 0                             |
| 方差          | \(1/12 \approx 0.0833\)    | 1                             |
+ 生成其他范围的均匀分布，用**缩放和平移**：```uniform_neg1_to_1=torch.rand(5)*2-1```(在[-1,1)范围)
**使用场景**：
+ **rand**:初始化权重（小范围）、Dropoout掩码、数据增强
+ **randn**:初始化神经网络权重（Xavier/He初始化）、添加噪声
