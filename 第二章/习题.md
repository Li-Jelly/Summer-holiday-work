### torch 和 tensor的区别
正确写法是```torch.tensor()``` ```torch.zeros()``` ```torch.ones()```
+ **torch**：模块名
+ **tensor**：函数名
+ **zeors**：函数名
+ **ones**：函数名
+ **命名规则**：torch.函数名()
+ ```tensor```不是一个独立的对象，只是```torch```模块里的一个函数
+ 所有PyTorch的函数都在```torch```这个命名空间下
+ 除非提前执行了```from torch import tensor```,然后才可以写```tensor(...)```，但仍不能写```tensor.zeros(...)```
### rand 和 randn的区别
+ **rand**:均匀分布，取值在[0,1)之间
+ **randn**:标准正态分布（均值为0，方差为1），取值理论上在（-∞，+∞）之间

| 特性          | `torch.rand()`             | `torch.randn()`               |
|:---------------:|:-------------------------:|:-------------------------------:|
| 分布名称      | 均匀分布                   | 标准正态分布                  |
| 取值范围      | \([0, 1)\)                 | 理论上 \((-\infty, +\infty)\)，实际约 \([-3, 3]\) |
| 概率密度      | 每个值概率相等             | 中间值概率高，两端概率低      |
| 均值          | 0.5                        | 0                             |
| 方差          | \(1/12 \approx 0.0833\)    | 1                             |
+ 生成其他范围的均匀分布，用**缩放和平移**：```uniform_neg1_to_1=torch.rand(5)*2-1```(在[-1,1)范围)
**使用场景**：
+ **rand**:初始化权重（小范围）、Dropoout掩码、数据增强
+ **randn**:初始化神经网络权重（Xavier/He初始化）、添加噪声

### ```numel()```计算元素总位置数而非值总和
```
x=torch.randn(2,3,4)
```
+ **确定张量的形状**：2*3*4=24
+ **填充随机数**：每个位置填入一个随机值

```numel()```只依赖于张量的```shape```属性，不依赖与```data```

### ```unsqueeze``` 和 ```squeeze```（互为逆操作）
|操作|字面意思|功能|维度数量|
|:---:|:---:|:---:|:---:|
|```squeeze```|挤压、压缩|**移除**维度大小为1的维度（去掉冗余信息）|减少|
|```unsqueeze```|解压、展开|**增加**维度大小为1的维度（恢复原始大小）|增加|
#### 为什么是维度1，而不是其他数字
**核心原因**：维度大小为1的维度“没有信息量”
|是否保留|含义|对数据的影响|
|:----:|:----:|:----:|
|保留：形状（1，3，4，5）|“1组，每组3张图片”|数据本质没变，但多了一层包|
|移除：形状（3，4，5）|“3张照片”|数据本质没变，去掉了多余的包装|
维度大小为1不增加任何信息量，可以安全移除（squeeze）
#### 为什么又要增加（unsqueeze）
因为很多模型/函数要求特定的维度数量
```
#场景：PyTorch的Conv2d要求输入是（batch,channel,height,width）
#如果只有一张灰度图（height,width）
img=torch.randn(28,28)    #形状（28，28）

#直接送入模型会报错，需要先加维度
img=img.unsqueeze(0)      #(1,28,28)  batch维度
img=img.unsqueeze(0)      #(1,1,28,28)  batch+channel维度
#现在可以送入了
```
unsqueeze是为了**对齐格式**，在需要的地方临时添加一个大小为1的维度
#### 形相类比
+ ```squeeze```（压缩）：拆掉外面多余的包装盒
+ ```unsqueeze```（解压）：给包裹加一层保护壳
把```un-```理解为**撤销**```squeeze```这个动作
```
import torch

x=torch.randn(1,3,1,4)
print(x.shape)            #torch.Size([1,3,1,4])

#移除所有大小为1的维度
y=x.squeeze()
print(y.shape)            #torch.Size([3,4])   两个1都被移除了

#只移除指定位置的大小为1的维度
z=x.squeeze(dim=0)
print(z.shape)            #torch.Size([3,1,4])  只移除了第1维

#如果指定位置的大小部位1，则不做任何事
w=x.squeeze(dim=1)        #dim=1 大小是3
print(w.shape)            #torch.Size([1,3,1,4])  不变
```
#### 为什么需要增加/移除维度
```
# 场景1：神经网络要求输入有 batch 维度
# 单张图片 (3, 224, 224) → 加上 batch 维度变成 (1, 3, 224, 224)
img = torch.randn(3, 224, 224)
img_batch = img.unsqueeze(0)  # (1, 3, 224, 224)

# 场景2：广播运算需要维度对齐
# 计算每个样本减去全局均值
x = torch.randn(10, 20)       # (10, 20)
mean = x.mean()               # 标量
x_centered = x - mean         # 标量可以广播，没问题

# 但如果均值是 (10,) 形状，需要 unsqueeze 对齐
means = x.mean(dim=1)         # (10,)
x_centered = x - means.unsqueeze(1)  # (10,20) - (10,1)
```
| 函数 | 作用 | 示例输入形状 | 输出形状 |
|:---:|:---:|:---:|:---:|
| `x.squeeze()` | 移除所有大小为1的维度 | `(1,3,1,4)` | `(3,4)` |
| `x.squeeze(dim=n)` | 只移除指定位置的大小为1的维度 | `(1,3,1,4)` | `(3,1,4)` |
| `x.unsqueeze(dim=n)` | 在指定位置增加大小为1的维度 | `(3,4)` | `(1,3,4)` |
| `x.unsqueeze(-1)` | 在最后增加维度 | `(3,4)` | `(3,4,1)` |
### 展平一维用的函数
```
import torch
x=torch.randn(2,3,4)

#方法1：flatten()-最直观，专门用于展平
y1=x.flatten()
print(y1.shape)               #torch.Size([24])

#方法2：reshape(-1)- -1表示“自动计算这个维度的大小”
y2=x.reshape(-1)
print(y2.shape)

#方法3：view(-1)-和reshape类似，但要求内存连续
y3=x.view(-1)
print(y3.shape)               #torch.Size([24])
```
#### 三种方法的区别
|方法|特点|使用场景|
|:---:|:---:|:---:|
|```x.flatten()```|最直观，专门用于展平|推荐，代码可读性最好|
|```x.reshape(-1)```|通用重塑，自动计算维度|需要同时改变多个维度时用|
|```x.view(-1)```|类似reshape，要求内存连续|性能略高，但不够灵活|
### 函数式编程原则（非原地操作）
+ **不修改原对象**
+ **返回一个新的张量**
|操作类型|函数名特征|是否改变原值|举例|
|:---:|:---:|:---:|:---:|
|非原地操作|无下划线|不改变|```flatten()``` ```reshape()``` ```sum()```|
|原地操作|有下划线|改变|```add_()``` zero_()``` ```copy_()```|
