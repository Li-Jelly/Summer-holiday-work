## 数据操作————张量
张量是深度学习中最基本的数据结构，可以理解为**多维数组**  
+ **标量（0维）**：单个数值，如```torch.tensor(3.0)```
+ **向量（1维）**：一维数组，如```torch.tensor([1,2,3])```
+ **矩阵（2维）**：二维数组，如```torch.tensor([1,2],[3,4])```
+ **高维张量（3维及以上）**：如图像数据通常为（批量大小，通道，高，宽）

## 线性代数基础
+ **向量点积（内积）**： $x^\top y = \sum\limits_{i} x_i y_i$
+ **矩阵乘法**：**AB**，要求**A**的列数等于**B**的行数
+ **范数**：
  L2范数： $\|x\|_2 = \sqrt{\sum\limits_{i} x_i^2}$（欧几里得距离）  
  L1范数： $\|x\|_1 = \sum\limits_{i} |x_i|$（曼哈顿距离）  
  矩阵范数： $\|A\|_F = \sqrt{\sum\limits_{i,j} A_{ij}^2}$(frobenius范数)

## 微积分与梯度
+ **导数**：函数在某点的变化率，$f'(x) = \lim\limits_{h \to 0} \frac{f(x+h) - f(x)}{h}$
+ **偏导数**：多变量函数对某一变量的导数，其余变量视为常数
+ **梯度**：将所有偏导数组成的向量，$\nabla f(x) = \left[\dfrac{\partial f}{\partial x_1}, \dots, \dfrac{\partial f}{\partial x_n}\right]^\top$
+ **链式法则**：复合函数求导，$\dfrac{\mathrm{d}}{\mathrm{d}x} f(g(x)) = f'(g(x)) \cdot g'(x)$
+ **梯度下降的核心思想**：沿着负梯度方向更新参数，使损失函数下降

## 自动微分
PyTorch的核心机制，自动计算梯度，省去手动推导的麻烦
+ **关键设置**：```x.requires_grad_(True)``` ```torch.tensor(...,requires_grad=True)
+ **反向传播**：```y.backward()```计算梯度，结果保存在```x.grad```中
+ **梯度清零**：```x.grad.zero_()```，否则梯度会累加
+ **分离计算图**：```y.detach()```用于需要数值但不需要梯度的场景
+ **控制流与梯度**：即使计算过程中有if/for等控制语句，PyTorch仍能正确计算梯度
